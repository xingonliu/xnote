## 1. 已确认规则

### 1.1 模型与附件

- 模型由用户自行配置，只适配 OpenAI、Anthropic、Gemini 三家的接口协议。
- 用户填写 API Key、模型名称和服务地址；自定义服务地址仍需遵循这三种协议之一。
- 保留唯一对话时间线；对话页不提供模型切换。当前运行、后续补充和排队任务固定使用同一配置，失败也不自动换模型。模型管理仅在设置页进行，运行或队列未处理完时禁止替换、删除当前使用的配置。
- 输入附件支持图片、PDF、纯文本和 Markdown，不自动导入笔记库。
- 发送前按所选模型的实际能力检查输入类型，不支持时明确提示。
- 对话、片段摘要、画像提取和笔记摘要共用对话模型，不提供独立摘要模型配置。协议、能力检查与配置方式见第 3 节 D01–D02。
- Agent 可返回纯文本和 Markdown 文件，由应用生成附件并提供预览、保存和分享；S11 不接入独立图片生成服务。

### 1.2 权限与数据范围

| 等级 | 能力 |
| --- | --- |
| 一级：不可查看（初始默认） | 不访问笔记库；主动附加笔记可临时读取其发送快照，不获得编辑权限。 |
| 二级：可查看 | 在授权范围内搜索、读取笔记，不能创建、修改或删除。 |
| 三级：可编辑 | 在授权范围内搜索、读取、创建、修改、删除笔记。 |

- 初始数据范围为“仅主动附加的笔记”；可选择未归档、指定笔记本或全部笔记。
- 等级与范围独立，提升等级不扩大范围。三级可编辑范围内的附加笔记。
- 降低权限或缩小范围立即生效；后续模型请求、工具执行和后台摘要重新检查权限。
- 未授权笔记的标题、摘要、正文、搜索结果及命中数量均不提供给模型。
- Agent 删除只移入回收站，不提供永久删除工具。

### 1.3 对话运行与队列

- 运行中默认把新消息补充到当前任务；另提供“加入队列”，等待当前任务结束后执行。
- 排队消息支持编辑、删除和排序；等待授权或处理冲突时不启动下一项。
- 正常完成后继续队列，未审阅 Diff 可以保留；同一篇再次修改时累计到该篇待审阅 Diff。
- 停止或失败时暂停队列，不自动跳过失败任务执行下一项。
- 离开 Agent 页面、切后台或锁屏后继续任务，通过系统通知展示状态并提供停止入口。
- 系统终止进程后保留已生成内容、已应用改动和待审阅 Diff；重启显示中断，由用户选择继续。
- 停止只阻止后续执行，不自动回退已应用改动。
- 片段仍按 30 分钟无新交互、容量边界和明确新话题关闭；运行或等待用户期间不按时间强行拆分。

### 1.4 实时应用与单篇 Diff

- 创建、修改、删除实时应用；每篇独立提供“全部接受”和“全部拒绝”，不提供逐处审阅。
- 单篇审阅范围是该篇自上次审阅后全部尚未接受的 Agent 改动，可以跨多轮任务累计。
- 接受确认保留已应用的改动，清除该篇待审阅状态；接受不是首次保存正文。
- 拒绝只撤销 Agent 改动，保留用户编辑，不以整篇旧快照覆盖最新正文。
- Agent 应用前检查最新版本：不重叠的修改可以合并；同一处冲突保留用户输入，重新读取并调整。
- 拒绝发现冲突时暂停整次回退，不部分回退；用户可以保留当前内容，或让 Agent 基于最新内容重新调整。
- 创建的笔记可以整体拒绝；删除立即移入回收站，对话保留删除卡片，接受保留删除结果，拒绝恢复。
- 未审阅 Diff 在退出、重启后保留；用户自己的编辑与 Agent 改动必须能区分来源。
- Diff 标记及审阅状态独立存储，不写进 `NoteDocument`；正文与审阅记录需要一致地持久化。

### 1.5 附加笔记版本

- 发送时保存内容快照，卡片绑定笔记 ID、版本及快照；仅有内容哈希不足以还原旧内容。
- 一级临时读取只覆盖该快照，原笔记后续修改不会扩大授权；当前片段关闭后临时授权失效。
- 二级、三级在当前范围允许时可主动读取最新版本，明确区分发送快照与当前内容。
- 三级编辑检查最新正文，不根据旧快照直接覆盖。
- 原笔记进入回收站后，快照停止向模型提供；永久删除时清理关联快照。
- 历史上下文、检索、摘要及工具读取均遵守当前权限和删除状态。

### 1.6 自动记忆

- 默认开启，可在 Agent 设置中关闭；开关控制长期画像的自动新增和更新。
- 关闭后已有记忆仍可使用、查看和删除；用户明确要求“记住”时仍可保存。
- 对话保存与上下文压缩继续运行；关闭开关不等于删除历史，也不等于禁止使用已有画像。
- 继续遵守来源、替换链、遗忘标记和用户更正规则。

## 3. 实施规则与参数责任

D01–D02 遵循用户指定的 NCXMUSIC 配置方式、共用模型及对话中禁止切换要求；D03–D15 依据用户授权，参考主流 Agent 并结合 XNote 的结构化笔记和 Android 运行约束作出以下实施选择。这些是 XNote 的规则，不宣称各参考产品完全相同。技术参数由实现者在对应切片内通过官方资料、测试与联调确定并记录。

| 编号 | 主题 | 实施规则 | 验证切片 |
| --- | --- | --- | --- |
| D01 | 接口与配置 | 参考 NCXMUSIC 的多组 Profile：名称、协议、服务根地址、API Key、模型 ID、启用状态、默认项和能力验证。模型主页只显示已配置列表和新增按钮；新增与编辑进入独立页面。预设使用动态厂商目录与官方模型目录；厂商名称、官方基地址、接口适配信息和模型 ID 均来自远端，应用只固定主流厂商排序。常驻厂商与模型下拉复用公共组件，支持搜索、滚动与联动，主流厂商优先、同厂商模型按发布时间倒序。选择后自动补全官方地址、协议、模型和容量，使用所选厂商自己的 API Key。自定义手填服务地址和模型 ID，可选 OpenAI Chat Completions、Anthropic Messages、Gemini 流式生成三种协议。编辑页提供删除、默认项和文字/流式/工具能力验证，不把目录元数据当作能力验证。目录失败可重试，不阻塞自定义或已有配置。 | S11.2 |
| D02 | 共用模型与固定配置 | 不单独配置摘要模型，全部模型任务共用对话配置。对话页没有切换入口，当前运行、补充及队列绑定配置版本；后台任务记录模型版本。设置只在无运行、无待处理队列时允许变更当前配置，变更不会重写历史；后续任务采用明确保存的配置，未完成旧任务不得静默改用新模型。失效配置显示需处理，不自动切换或回退到其他服务商。 | S11.2 / S11.4 |
| D03 | 范围与新建归属 | 指定笔记本支持多选。用户明确指定且在可写范围内的目标优先；只有一个可写目标时使用该目标；多个目标且未指定时请用户选择。仅附加范围没有新建目标时请求用户明确归属及该次创建授权，新建笔记在本次运行内可继续操作，不扩大整个笔记本的授权。S11 不提供笔记本管理或移动既有笔记归属的工具。 | S11.1 / S11.5 / S11.7 |
| D04 | 授权与降级 | 三级授权范围内实时写入不重复询问，越界时请求授权。一次运行允许与始终允许分别保存为临时授权和用户配置，模型不能自行升级。用户降低等级或撤销范围优先于旧临时授权。用户仍可在本地接受或拒绝已经发生的改动；这不赋予模型继续读取或改写的权限。 | S11.1 / S11.5 |
| D05 | 可编辑内容 | 首版允许标题、文字块的正文/样式/清单和表格内容/结构；图片、贴纸、画笔、背景与归属保持不变。选区润色携带版本、块 ID 和文字范围。结构化操作经应用校验后提交；未知字段、非法结构和过期定位不能直接落库。全文改写不得删除或重排受保护媒体块。 | S11.1 / S11.6 / S11.7 |
| D06 | 审阅与回退边界 | 单篇接受结束当前审阅批次；提供最近一次已接受批次的撤回，保留 30 天，过期明确不可用；撤回仍保护后续用户编辑并按整篇冲突检查。拒绝新建遇到用户新增内容时暂停，不删除用户内容。删除拒绝时若已被用户恢复则保留当前版本，原笔记本消失则恢复到未归档。回收站仍按 30 天清理，不因待审阅无限保留；永久删除后清理关联快照并把卡片标为无法恢复。其他正常笔记的未审阅记录保留至审阅或用户明确清除。 | S11.1 / S11.6 / S11.7 |
| D07 | 容量与预算 | 依据配置的模型容量预留输出和工具预算，接近容量时压缩已完成历史。单条输入过大则发送前提示缩减或分批；运行中超限在完整模型/工具交互边界压缩已完成部分，保留当前目标与未完成调用。容量切片只在安全边界关闭；不能容纳的最小请求暂停并保留内容。提供“开始新话题”操作，不清除时间线。各预算数值在 S11.3、S11.8 内记录与验证。 | S11.3 / S11.8 |
| D08 | 补充、取消与重试 | 补充在下一安全执行边界进入当前任务，不自行撤销已应用改动。取消阻止后续请求与工具派发，正在提交的本地事务先确定结果。只对可重试的网络/服务错误做有限退避重试，认证、配额及非法请求直接提示。继续前读取工具提交记录，已成功写入不重放，结果未知先核查；等待授权不默许，取消后重新请求。次数、超时与等待状态的恢复规则在运行契约中固定。 | S11.4 |
| D09 | 后台受限 | 页面离开、后台和锁屏继续执行是正常路径；通知被拒或后台受限时说明可见性/执行限制，保留应用内停止入口。无法继续时进入可恢复中断状态，回到前台由用户继续，不能假装后台仍运行。循环与资源达到上限同样暂停；具体平台机制和上限由 S11.4 在真实 Android 环境验证。 | S11.4 |
| D10 | 快照与删除传播 | 快照保存结构化正文及媒体引用，独立计算附件引用，不重复拷贝媒体。不同发送版本分别绑定卡片，相同版本可复用快照。清除聊天解除其快照引用，仍被笔记或有效改动记录引用的附件保留。删除、撤权使所有后续模型请求、检索和摘要重新做安全投影；历史回复包含笔记派生内容时保留来源标记，无权限的内容不重传，无法细分来源时排除整个相关条目。 | S11.5 / S11.10 |
| D11 | 自动记忆与费用 | 重新开启不追补关闭期间的内容；自动候选落库前重查开关和来源时段，关闭前在途任务也不能在关闭后写入。明确要求记住的请求单独处理。敏感或冲突不清的画像等待用户确认。片段关闭后生成摘要，笔记编辑稳定后去抖生成；网络不可用延后，前台对话优先。调用去重并设累计调用/Token 限额，超限暂停派生任务；按任务类型显示用量。 | S11.8 / S11.9 / S11.10 |
| D12 | 附件输入 | 图片采用应用可解码的静态格式，动画取首帧；文本及 Markdown 先按 UTF-8 读取，编码失败提示转换。PDF 按模型支持走原生文件输入或提取文本，扫描件无法可靠提取且模型不支持时明确提示。发送前校验体积、数量、页数和预算，具体限额取本地上限与服务能力较小值。不支持时保留草稿并提示移除或缩减，不在对话中切换模型。仅文字模型可聊天，不伪装支持工具或附件。 | S11.11 |
| D13 | 输出文件 | Agent 输出文字及纯文本/Markdown 文件，应用将生成文本保存为本地附件，提供预览、保存和系统分享，不自动创建笔记。S11 不新增独立图片生成服务、可执行脚本或 Office 文件生成环境；既有媒体引用与新图片生成分开处理。 | S11.11 |
| D14 | 凭据与数值 | 凭据使用平台受保护存储，不进入日志、消息或普通备份；配置导出不含秘密。能力测试前提示可能产生服务费用。用量以服务返回 Token 为准，估算须标明；无可靠价格不显示金额。超时、重试、循环、分页、附件及缓存配额由实现者确定有限默认值，记录在集中配置及验收文档，不要求用户逐个设置。 | S11.2 起，所属切片完成前 |
| D15 | 页面与历史 | 已发送消息保持事实记录，可复制或以新消息重发；首版不原地编辑旧消息、不建立分支。失败重试与继续追加执行事件，不隐式回退笔记；不提供已完成任务的一键重新生成。默认名称固定“Agent”。支持删除消息及清除聊天并失效派生数据；清除前停止运行、清空队列，未审阅 Diff 保留独立入口。手机以单时间线和抽屉呈现详情，平板可并排展示详情；具体尺寸沿用公共设计系统。 | S11.4 / S11.12 |

## 4. 交付与验证约定

- 产品规则以第 1、3 节为准；实现各子切片时同步参数值、测试依据和相关文档，不把文档完成标成 S11 功能交付。
- 每个子切片运行对应单元、数据库或界面验证；后台、中断和系统权限行为需要真实 Android 环境验证。
- 权限、冲突和重试测试以用户可观察结果与数据一致性为准，覆盖同篇编辑、重复提交、进程死亡和权限收紧。
- 三家服务分别完成实际联调；无有效凭据时标记联调未完成，不用模拟测试替代。
- S11 不包含 S12 的图像创作能力和 S13 的 MCP、Skill、Linux 执行环境。

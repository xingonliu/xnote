## 1. 已确认规则

### 1.1 模型与附件

- 模型由用户自行配置，只适配 OpenAI、Anthropic、Gemini 三家的接口协议。
- 用户填写 API Key、模型名称和服务地址；自定义服务地址仍需遵循这三种协议之一。
- 保留唯一对话时间线，切换模型不创建新的对话历史。
- 输入附件支持图片、PDF、纯文本和 Markdown，不自动导入笔记库。
- 发送前按所选模型的实际能力检查输入类型，不支持时明确提示。
- 摘要模型的配置方式与协议端点等未定细节见第 3 节，不预设所有模型都有工具、多模态或文件能力。

### 1.2 权限与数据范围

| 等级 | 能力 |
| --- | --- |
| 一级：不可查看（初始默认） | 不访问笔记库；主动附加笔记可临时读取其发送快照，不获得编辑权限。 |
| 二级：可查看 | 在授权范围内搜索、读取笔记，不能创建、修改或删除。 |
| 三级：可编辑 | 在授权范围内搜索、读取、创建、修改、删除笔记。 |

- 初始数据范围为“仅主动附加的笔记”；可选择未归档、指定笔记本或全部笔记。
- 等级与范围独立，提升等级不扩大范围。三级可编辑范围内的附加笔记。
- 降低权限或缩小范围立即生效；后续模型请求、工具执行和后台摘要重新检查权限。
- 未授权笔记的标题、摘要、正文、搜索结果及命中数量均不提供给模型。
- Agent 删除只移入回收站，不提供永久删除工具。

### 1.3 对话运行与队列

- 运行中默认把新消息补充到当前任务；另提供“加入队列”，等待当前任务结束后执行。
- 排队消息支持编辑、删除和排序；等待授权或处理冲突时不启动下一项。
- 正常完成后继续队列，未审阅 Diff 可以保留；同一篇再次修改时累计到该篇待审阅 Diff。
- 停止或失败时暂停队列，不自动跳过失败任务执行下一项。
- 离开 Agent 页面、切后台或锁屏后继续任务，通过系统通知展示状态并提供停止入口。
- 系统终止进程后保留已生成内容、已应用改动和待审阅 Diff；重启显示中断，由用户选择继续。
- 停止只阻止后续执行，不自动回退已应用改动。
- 片段仍按 30 分钟无新交互、容量边界和明确新话题关闭；运行或等待用户期间不按时间强行拆分。

### 1.4 实时应用与单篇 Diff

- 创建、修改、删除实时应用；每篇独立提供“全部接受”和“全部拒绝”，不提供逐处审阅。
- 单篇审阅范围是该篇自上次审阅后全部尚未接受的 Agent 改动，可以跨多轮任务累计。
- 接受确认保留已应用的改动，清除该篇待审阅状态；接受不是首次保存正文。
- 拒绝只撤销 Agent 改动，保留用户编辑，不以整篇旧快照覆盖最新正文。
- Agent 应用前检查最新版本：不重叠的修改可以合并；同一处冲突保留用户输入，重新读取并调整。
- 拒绝发现冲突时暂停整次回退，不部分回退；用户可以保留当前内容，或让 Agent 基于最新内容重新调整。
- 创建的笔记可以整体拒绝；删除立即移入回收站，对话保留删除卡片，接受保留删除结果，拒绝恢复。
- 未审阅 Diff 在退出、重启后保留；用户自己的编辑与 Agent 改动必须能区分来源。
- Diff 标记及审阅状态独立存储，不写进 `NoteDocument`；正文与审阅记录需要一致地持久化。

### 1.5 附加笔记版本

- 发送时保存内容快照，卡片绑定笔记 ID、版本及快照；仅有内容哈希不足以还原旧内容。
- 一级临时读取只覆盖该快照，原笔记后续修改不会扩大授权；当前片段关闭后临时授权失效。
- 二级、三级在当前范围允许时可主动读取最新版本，明确区分发送快照与当前内容。
- 三级编辑检查最新正文，不根据旧快照直接覆盖。
- 原笔记进入回收站后，快照停止向模型提供；永久删除时清理关联快照。
- 历史上下文、检索、摘要及工具读取均遵守当前权限和删除状态。

### 1.6 自动记忆

- 默认开启，可在 Agent 设置中关闭；开关控制长期画像的自动新增和更新。
- 关闭后已有记忆仍可使用、查看和删除；用户明确要求“记住”时仍可保存。
- 对话保存与上下文压缩继续运行；关闭开关不等于删除历史，也不等于禁止使用已有画像。
- 继续遵守来源、替换链、遗忘标记和用户更正规则。

## 2. 开发顺序与验收

所有子切片当前均为待开发。每片交付实现、相关文档和必要验证后再进入下一片；产品选择未定时只阻塞依赖它的工作，不将建议当成已确认需求。

```text
S11.1 事实源与权限基础
 → S11.2 三家模型接入与配置
 → S11.3 单时间线与流式对话
 → S11.4 运行控制、队列与后台恢复
 → S11.5 笔记快照、范围与只读工具
 → S11.6 实时改动记录与单篇 Diff
 → S11.7 创建、修改、删除与编辑联动

 → S11.9 画像与自动记忆开关
 → S11.10 文档记忆与记忆工具
 → S11.11 图片和文件消息
 → S11.12 全链路验收与收尾
```

| S11.11 图片和文件消息 | 图片、PDF、纯文本、Markdown 导入与消息卡片、模型能力校验、发送预算及附件生命周期；P23 占用说明。依赖 S11.10；S11.1 预留附件关联。 | 四类输入分别验证；不支持、过大、损坏与取消不丢草稿；不自动建笔记；切模型重新检查；删除聊天回收不再引用附件。D12、D13 已定。 |

S11.3 即可验收真实文字对话，S11.7 形成可操作笔记的闭环；长期记忆在事实源和权限可验证之后接入。开发中可以使用受控测试数据，但不能把假模型响应作为真实服务联调完成的证据。

## 3. 全部未定项

以下列出当前影响产品行为、实现边界和验收的未定项。表中建议是讨论起点，不是已确认规则；参数由实现验证确定的项目无需逐个请求用户批准，但必须在对应切片完成前记录具体值和证据。

| D01 接口与配置 | OpenAI 首版采用哪种接口形态，是否同时适配多种；配置是否允许多组、模型如何获取；自定义地址的认证和连接限制。 | 用户选择三种协议已确定；具体端点和参数通过实施时的官方文档与联调选择。建议允许多组配置、手填模型并提供能力检查；不承诺任意“兼容”端点全部可用。 | S11.2 |
| D02 摘要模型与切换 | 对话、片段摘要、画像提取、笔记摘要是否共用模型；能否另配；切换配置如何影响在途运行和排队任务。 | 建议摘要默认复用对话配置、可单独指定；运行固定配置快照，切换用于后续运行；不在失败时擅自换服务商。该建议尚待确认。 | S11.2 |

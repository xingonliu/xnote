# XNote Agent 气泡复刻说明

视觉目标为用户提供的 iMessage 参考图，气泡正文按当前要求与 Tabbar 共用 12 sp 字号。以下轮廓、色值、透明度、模糊半径与间距是 Android 适配参数。

## 公开资料

- [Apple — Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 说明 Liquid Glass 主要服务于浮动导航与控件层，内容层应保持清晰。据此结合参考图，发送气泡采用蓝色填充，接收气泡采用安静的磨砂表面；按钮的透镜、高光与投影不直接用于消息正文。
- [Apple — Add backgrounds in Messages on iPhone](https://support.apple.com/en-asia/guide/iphone/iph605fa06e4/ios) 说明 iMessage 会话可使用照片或动态背景，背景能力支持 iOS 26 及之后的版本。参考图中的雨滴是会话背景，气泡通过材质透出背景颜色。
- [Swift Chat 作者的复刻说明](https://unionst.com/swiftchat/) 描述按连续发言与约一分钟间隔控制尾部，以及气泡尺寸、滚动和键盘的细节。此资料为复刻作者的观察，60 秒分组规则作为项目逻辑使用。
- [AndroidLiquidGlass 源码与文档](https://github.com/kyant0/AndroidLiquidGlass) 提供背景捕获、模糊、自定义轮廓及表面绘制；实现沿用仓库固定的 Backdrop 2.0.1，不新增渲染依赖。

这些材料未给出 iOS 27 iMessage 气泡完整的内部材质配方和路径参数。参考图也包含拍摄、压缩与屏幕色彩的影响，因此不能将适配值宣称为 Apple 系统的精确参数。

## 材质与排版

| 项目 | 实现 |
| --- | --- |
| 发送侧 | 白色正文，不透明蓝色；可见聊天区域顶部 `#32A5FF` 至底部 `#087AFF` 共用一个渐变 |
| 发送侧滚动 | 按气泡在窗口中的位置取色，滚动时渐变持续对齐视口；读取位置状态发生在绘制阶段 |
| 接收侧浅色 | 单独采样背景，12 dp 模糊，`#D1D1D6`／56% 表面着色，黑色正文 |
| 接收侧深色 | 单独采样背景，12 dp 模糊，`#48484A`／62% 表面着色，白色正文，0.5 dp／10% 白色细边线 |
| 高对比度 | 不透明 `#0066D9`／`#E5E5EA`／`#2C2C2E` 底色及白色／黑色正文 |
| 字号 | 气泡与 Tabbar 共用 `XNoteBottomTabFontSize`，当前 12 sp，气泡行高 16 sp，常规字重，字距 0 sp |
| 缩放 | 共用应用主题的 Density，系统与应用字体倍率同时生效 |
| 宽度 | 随内容收缩，包含尾部或对齐占位后最多为可用宽度的 80%，且不超过 360 dp |
| 主体 | 最大 20 dp 圆弧圆角，根据宽高收缩；单行自然形成胶囊，多行保持圆角矩形 |
| 内边距 | 左右 12 dp、上下 7 dp，尾侧加 6 dp、底部加 4 dp 以隔开文字和尾部 |
| 尾部 | 与主体共用一条轮廓，外伸 6 dp、下延 4 dp，外侧下扫、内侧回收，随 LTR／RTL 镜像 |

接收气泡采样层只包含页面背景，避免正文进入自身模糊采样。当前 Agent 页面为主题纯色背景，磨砂材质呈现相应的中性灰色。

## 分组逻辑

同片段、相邻、间隔为 0–60 秒的已完成纯文字用户消息成组；组内间距为 3 dp，仅组末显示尾部。文件、笔记快照、待处理状态、任务、事件和角色切换构成分组边界，其他时间线条目间距为 10 dp。文字之后有附件或快照时，正文不显示尾部。

无尾气泡在发言侧保留 6 dp 外部占位，主体外壁和文字起点与带尾气泡对齐；达到最大宽度时也保留相同的主体宽度。结束语的非空行以 3 dp 间距成组，仅最后一行显示尾部。

## 验证范围

分组单元测试覆盖时间边界、倒序时间、片段、角色、附件、快照、待处理状态与任务条目。Debug 构建、JVM 单元测试、Android UI 测试源码编译与 `lintDebug` 均通过；单元测试共 228 项，227 项通过、1 项跳过，Lint 无错误。当前没有连接 Android 设备，未启动模拟器，真机材质与参考图的视觉比对尚未执行。

# XNote 开发顺序

> 文档版本：v0.1
>
> 文档状态：按已确认决策执行的开发切片
>
> 依据：[功能清单与页面组成](./XNote%20功能清单与页面组成.md)、[UI 设计规范](./XNote%20UI%20设计规范.md)
>
> 产品里程碑仍对应功能清单第 7 节的四个阶段；本节把第一阶段拆成可独立验收的切片，并给出后续阶段的进入条件。

## 1. 已确认决策

| 主题 | 结论 |
| --- | --- |
| 第一阶段怎么做 | 按本文切片逐步交付，不把功能清单 7.1 当作单次里程碑一次性做完。 |
| 普通笔记文字 | 对齐 Apple Notes 编辑能力全套：段落样式、行内样式、清单、检查清单、引用、缩进、对齐、高亮、表格、标题折叠。 |
| 删除笔记本 | 笔记本立即消失且不可恢复；其中笔记全部进入回收站；恢复后变为未归档。 |
| 笔记背景 | 内置预设 + 用户从相册选择的图片；两级规则（默认背景 + 单篇覆盖）不变。 |
| 不做的“Apple Notes 全套” | 不同步 iCloud、协作、标签、密码锁、扫描件、录音、数学笔记；XNote 已有自己的笔记本、回收站、Markdown、Agent 与画笔模型。 |

## 2. 当前基线

仓库 `main` 已具备：

- Android 13+ / Jetpack Compose 工程、主题、令牌、60% 平滑圆角。
- 手机 `LiquidBottomTabs`、官方 `LiquidButton`、项目级 `XNoteLiquidGlassPanel` 与平板 Navigation Rail。
- 一级目的地外壳：笔记 / Agent / 我的；搜索入口打开占位页。
- 笔记首页空状态；新建笔记按钮存在但未接通。

尚未开始：

- 本地数据库、领域模型、ViewModel / Repository。
- `XNoteScrollEdgeEffect`、通用 Header 右侧槽、Dialog / Drawer / Toast / Popup / Dropdown。
- 任何笔记 CRUD、Markdown、搜索、回收站、阅读、导出、背景资源、Agent。

## 3. 总顺序

```text
S1 设计系统补齐
 → S2 本地数据层
 → S3 笔记本与普通文字笔记（含完整富文本）
 → S4 Markdown 与单向转换
 → S5 回收站与搜索
 → S6 笔记背景
 → S7 图片基础插入与变换
 → S8 阅读模式
 → S9 导出图片
 → S10 平板多栏、我的、统计与外观
 → S11 Agent 对话与笔记工具          （功能清单第二阶段）
 → S12 抠图、贴纸、环绕布局、画笔    （功能清单第三阶段）
 → S13 MCP、Skill、Linux            （功能清单第四阶段）
```

约束：

- 未完成 S1 时不铺新业务页，避免每个页面私有骨架、浮层和 Header。
- S2 的文档模型按完整富文本一次性设计；S3 编辑器按“可编辑正文 → 样式与清单 → 表格 → 标题折叠”增量实现。
- 图片、贴纸、画笔的 UI 分别在 S7 / S12，但 S2 就要留下对应块类型，避免后期改存储。
- 统计、存储占用、外观中的主题与辅助功能不阻塞笔记闭环，放到 S10；默认背景选择在 S6 先做最小设置入口。

## 4. 切片详情

### S1 设计系统补齐

**目标：** 后续页面只组公共组件，不再复制玻璃材质、Header 或浮层。

**交付：**

- `XNotePageScaffold` 接入系统栏、Toast Host、页面级加载/错误，以及顶部/底部 `XNoteScrollEdgeEffect`（`Soft` / `Hard`）。
- `XNoteHeader` 支持左侧返回、居中标题、右侧 0–2 个功能按钮；无右侧按钮时保留等宽占位。一级目的地继续用当前外壳 Header（标题 + 搜索）；二级页面必须走标准 Header。
- `XNoteDialog`、`XNoteDrawer`、`XNoteToastHost`、`XNotePopup`、`XNoteDropdownMenu`。
- `XNoteLoadingState`、`XNoteEmptyState`、`XNoteErrorState`。
- 编辑器格式工具栏组件 `XNoteRichTextToolbar` 先定 API 与视觉，S3 再接到文档命令。

**不做：** 背景选择器、笔记画布、业务数据。

**验收：** 用笔记首页和两个占位页验证 Scroll Edge、浅色/深色、减少动画、平板与手机；无页面私有圆角或私有按钮材质。

### S2 本地数据层

**目标：** 本地笔记库可读写，搜索和回收站有表结构，附件有目录约定。

**工程约定：**

- 持久化使用 Room（SQLite）。全文检索使用 FTS5；中文连续字串必须能命中，分词策略在 S5 验收时验证。
- 普通笔记正文存为自有 JSON 文档，不把 HTML 或 Markdown 当作源格式。
- 附件（用户背景图、后续图片/贴纸/画笔）放在应用私有文件目录，库中只存稳定 ID 与元数据。
- 设置（默认背景、主题等）与笔记库分开存储。
- 回收站清理用应用启动补扫 + 系统允许的后台任务，不承诺第 30 天的精确时刻。

**交付：**

- 实体：笔记本、笔记、文档块、附件、历史版本、设置。
- 笔记状态：正常 / 回收站；`deletedAt`、剩余保留天数的计算。
- 未归档：`notebookId == null`。
- 历史版本：第一版只服务“转 Markdown”和“Agent 润色撤回”，不提供通用版本浏览。
- 纯文本抽取：供搜索、摘要、字数统计复用。
- 领域规则的单元测试（删除笔记本、恢复归属、转换前置条件、字数口径）。

**块类型（S2 一次定稿）：**

```text
Note
├─ TextBlock      # 段落、标题、清单、检查清单、引用、对齐、高亮
├─ TableBlock     # 表格；单元格只含文字与行内样式
├─ ImageBlock     # S7 才提供编辑 UI
├─ StickerBlock   # S12
└─ DrawingBlock   # S12
```

**不做：** 界面、假数据层长期驻留、云同步。

### S3 笔记本与普通文字笔记

**目标：** 用户可以建立笔记本、写下完整富文本笔记、自动保存、删除到回收站。

**交付页面：** P01 笔记首页、P02 笔记本详情、P03 普通笔记编辑页（文字与表格，无图片入口）。

**产品规则：**

- 在“全部笔记”或未归档下新建 → 未归档；在某笔记本内新建 → 属于该笔记本。
- 首页：当前范围、最近编辑、列表/网格所需的标题/摘要/时间/所属笔记本、空状态、长按多选。
- 笔记本：创建、重命名、删除确认；笔记数量与文字量；创建时间 / 更新时间 / 标题排序；手动拖动排序。
- 删除笔记本：笔记本记录立即永久删除；其下笔记全部进入回收站，并快照“原笔记本名称”仅供展示；恢复后 `notebookId` 为空。
- 删除空笔记本：直接消失，回收站无条目。
- 编辑页：标题在正文顶部；Header 中间不重复标题，可短暂显示保存状态；底部为格式工具栏与撤销重做。
- 自动保存；撤销重做作用于当前编辑会话，不写入历史版本表。
- 多选动作：移入回收站、移动到笔记本。

**富文本范围（S3 必须做完）：**

1. 段落样式：正文、标题、小标题、等宽。笔记标题是独立字段，正文不再提供与标题重复的 Title 样式。
2. 行内样式：粗体、斜体、下划线、删除线、链接、高亮。
3. 结构：无序（圆点 / 虚线）、有序、检查清单、引用、多级缩进。
4. 对齐：左、中、右。
5. 表格：默认 2×2；增删行列；单元格仅文字与行内样式，不能嵌图片。
6. 标题与小标题可折叠。

**内部顺序：** 先打通标题 + 正文 + 保存 + 列表，再接样式与清单，再接表格，最后接折叠。

**不做：** 图片/贴纸/画笔入口、Markdown、阅读、导出、背景选择、Agent。

**验收：** 冷启动后数据仍在；删除笔记本后笔记只出现在回收站数据中（S5 才做回收站页，S3 可用调试入口或仓库查询证明恢复规则）；字体放大与减少动画下编辑器仍可用。

### S4 Markdown 与单向转换

**目标：** 纯文字（含表格）的普通笔记可永久转为 Markdown；Markdown 笔记可编辑和预览。

**交付页面：** P04。

**规则：**

- 存在图片、贴纸或画笔块时禁用转换，并提示先移除这些内容。表格、清单、引用、检查清单允许转换。
- 转换前写一条历史版本；转换后立即进入 Markdown 编辑模式；不可转回普通笔记。
- 按块的显示顺序合并为 Markdown 原文，映射见第 6 节。
- 编辑模式右下角“✓”保存并进入预览；预览经编辑按钮返回编辑。

**不做：** 润色 Diff、图片消息、在 Markdown 中重新插入媒体。

### S5 回收站与搜索

**目标：** 删除可恢复，标题和正文可检索。

**交付页面：** P14、P17。

**回收站：**

- 列表展示标题、删除时间、剩余天数、原笔记本名称（若有）。
- 恢复、永久删除、清空、多选。
- 恢复时：原笔记本已不存在（含删除笔记本带入回收站的笔记）→ 未归档；若用户删除单篇且原笔记本仍在 → 回到原笔记本。
- 不参与普通列表、搜索、阅读、统计和 Agent Tool。
- 满 30 天后在启动补扫或后台任务中清理，并删除未被引用的附件。

**搜索：**

- 手机：独立全屏搜索页。
- 平板：在笔记列表栏顶部展开搜索框，结果仍按 P14 的信息结构展示。
- 标题与正文、按笔记本筛选、匹配片段高亮、最近搜索与清空。
- 回收站不参与。

**验收：** 中文连续子串（如“笔记本”命中“我的笔记本”）必须可用；若 FTS 分词导致漏检，S5 内改抽取或 tokenizer，不留到后续切片。

### S6 笔记背景

**目标：** 两级背景规则在编辑、预览中生效。

**交付：**

- `XNoteNoteSurface`、`XNoteBackgroundPicker`。
- 外观设置中的默认背景入口（P25 的背景子集，可先从“我的”进入，S10 再补全其余外观项）。
- 编辑页更多菜单：更换专属背景 / 使用默认背景；影响范围文案为“仅当前笔记”。
- 内置预设 + 相册导入；导入图存为附件，库中只存 ID。
- 资源缺失时回退默认背景，并用 Toast 提示，不阻止打开笔记。

**不做：** 导出合成（S9）、阅读模式切换背景（S8 接入同一解析器）。

### S7 图片基础插入与变换

**目标：** 普通笔记可插入照片，并做基础变换。

**交付：**

- 添加图片：相机、相册。贴纸入口等 S12 贴纸库完成后再露出。
- 缩放、旋转、移动、删除、替换、复制、前后层级。
- 第一版布局为块级插入（夹在相邻文字块之间），不做文字环绕或浮动。
- 手机底部 Drawer、平板锚定菜单；浮层与页面同一 Compose Host。

**不做：** 抠图、贴纸库、环绕/浮动、画笔。

### S8 阅读模式

**目标：** 按笔记本顺序分页阅读，背景与排版随当前笔记变化。

**交付页面：** P06。

**规则：**

- 多篇连续阅读只从笔记本进入。
- 编辑页“打开阅读模式”只阅读当前这一篇。
- “全部笔记”和未归档不提供整库连续阅读。
- 每篇从新页开始；长笔记可跨页；图片/贴纸/画笔剩余空间不足时整块移到下一页。
- 分页是派生数据，不写入数据库。
- 目录跳转、页码、进度、进入当前笔记编辑。

### S9 导出图片

**目标：** 导出结果与阅读/预览一致，并包含背景。

**交付页面：** P09。

**规则：**

- 短笔记单张，长笔记分页多张，避免超大 Bitmap。
- 任务开始时固定背景快照。
- 输出不含 Header、工具栏、按钮、Liquid Glass Overlay。
- 宽度与阅读内容宽度一致。
- 预览、保存到系统相册、系统分享。

### S10 平板多栏、我的、统计与外观

**目标：** 信息架构收口，设置与统计可用。

**交付：**

- 平板笔记区：侧边导航 | 笔记本列表 | 笔记列表 | 笔记内容。
- P15 我的：已实现能力给真入口，未实现能力（模型、Agent 权限、Skill、MCP、Linux）给说明性占位，不造假功能。
- P16 统计：按功能清单口径；趋势图不做。
- P25 其余项：浅色/深色/跟随系统、减少动画、高对比度、字体大小、阅读排版。
- P24 中与本地占用、缓存清理相关的部分；数据导入导出不做。

**不做：** Agent、MCP、Linux、云同步。

### S11 Agent 对话与笔记工具

对应功能清单 7.2。进入条件：S3–S5 可用，否则工具没有真实笔记可操作。

**交付：** P10–P13、P19、P20；`read` / `note_search` / `create` / `write` / `delete`；三级操作权限与数据范围；润色 Diff（接受全部 / 拒绝全部）；携带笔记卡片进入对话；图片与文件消息。

默认模型服务商在本切片开始前确认，见第 8 节。

### S12 抠图、贴纸、环绕布局、画笔

对应功能清单 7.3。进入条件：S7 图片块已稳定。

**交付：** P07、P08、P18；抠图与蒙版修正；贴纸库；文字环绕与浮动；画笔块与独立画板（第一版：笔、橡皮、颜色、粗细、撤销重做；压感/掌触/图层后续）。

抠图模型在本切片开始前做许可证、包体、内存和端侧兼容性验证。

### S13 MCP、Skill、Linux

对应功能清单 7.4。进入条件：S11 Agent Loop 稳定。

**交付：** P21–P23；远程 Streamable HTTP MCP；纯指令型 Skill（`SKILL.md`、references、assets）；Linux 沙箱后再开放本地 stdio MCP 与可执行脚本。

Linux 技术方案在本切片开始前确认。

## 5. 领域规则摘要

| 规则 | 说明 |
| --- | --- |
| 未归档 | 不属于任何笔记本的笔记；可移动进笔记本。 |
| 删除笔记本 | 笔记本永久删除；笔记进回收站；展示用原笔记本名称快照；恢复后未归档。 |
| 删除单篇笔记 | 进回收站；原笔记本仍在则恢复回原处，否则未归档。 |
| 历史版本 | 仅转 Markdown 前、润色接受前各保存必要快照。 |
| 字数 | 只统计可见文本；不含标题、图片文件名、画笔；中文字符数，英文可另计单词。 |
| 背景 | `专属背景 ?? 默认背景`；改默认立即作用于未覆盖笔记；新建笔记不拷贝默认值。 |
| 转换 | 有图片/贴纸/画笔则禁止；表格可转；转换不可逆。 |

## 6. 普通笔记 → Markdown 映射

| 普通笔记 | Markdown |
| --- | --- |
| 笔记标题字段 | 文档首行 `# 标题` |
| 正文标题 | `##` |
| 小标题 | `###` |
| 正文段落 | 普通段落 |
| 等宽 | 围栏代码块或行内 `` ` ``，按是否多行 |
| 粗体 / 斜体 / 删除线 | `**` / `*` / `~~` |
| 下划线 | `<u>`（标准 Markdown 无对应语法） |
| 高亮 | `==高亮==` |
| 链接 | `[text](url)` |
| 无序圆点 / 虚线 | `-` |
| 有序 | `1.` |
| 检查清单 | `- [ ]` / `- [x]` |
| 引用 | `>` |
| 对齐、折叠 | 转换后不保留，只保留文字 |
| 表格 | GitHub 风格管道表；单元格只出纯文本与行内样式 |
| 图片 / 贴纸 / 画笔 | 不允许转换 |

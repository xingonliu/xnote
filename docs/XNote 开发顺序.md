## 1. 已确认决策

| 主题 | 结论 |
| --- | --- |
| 第一阶段怎么做 | 按本文切片逐步交付，不把功能清单 7.1 当作单次里程碑一次性做完。 |
| 笔记正文 | 所有笔记统一使用结构化 JSON 文档，对齐 Apple Notes 编辑能力：段落样式、行内样式、清单、检查清单、引用、缩进、对齐、高亮、表格、标题折叠。 |
| Markdown | 不作为笔记类型或源格式；只提供可关闭的常用快捷输入和可选导出。快捷输入只处理本次键盘编辑，不静默转换已有内容或多行粘贴。 |
| 删除笔记本 | 笔记本立即消失且不可恢复；其中笔记全部进入回收站；恢复后变为未归档。 |
| 笔记背景 | 仅支持四款内置预设；两级规则（默认背景 + 单篇覆盖）不变。 |
| Agent 对话模型 | Agent 入口直接展示一条持续存在的对话时间线；内部片段只用于压缩和回溯。 |
| Agent 记忆 | 当前片段原文作为短期记忆；历史片段摘要、原子画像和独立文档记忆组成长期内容；完整规则以 Agent 记忆与上下文架构文档为准。 |
| 不做的“Apple Notes 全套” | 不同步 iCloud、协作、标签、密码锁、扫描件、录音、数学笔记；XNote 已有自己的笔记本、回收站、Markdown 快捷输入、Agent 与画笔模型。 |

## 2. 当前基线

仓库 `main` 已完成 S1–S10，并具备：

- Android 13+ / Jetpack Compose 工程、主题、令牌、60% 平滑圆角。
- 手机 `LiquidBottomTabs`、官方 `LiquidButton`、项目级 `XNoteLiquidGlassPanel` 与平板 Navigation Rail。
- 一级目的地外壳：笔记 / Agent / 我的；手机搜索进入全屏页，平板搜索保留 Navigation Rail 并在笔记列表栏展开。
- `XNotePageScaffold` 统一系统安全区、页面加载/错误、Toast Host 与 AndroidLiquidGlass Progressive blur，二级页面顶部和底部遮罩常驻。
- 标准 `XNoteHeader` 支持返回、居中标题和零至两个右侧操作；笔记首页与占位页复用公共状态组件。
- 公共 Dialog、Drawer、Toast、Popup、Dropdown，以及加载、空、错误状态和 `XNoteRichTextToolbar` API/视觉。
- 系统减少动画监听；关闭动画时禁用 Liquid Button、Bottom Tabs、Progressive blur 与浮层的弹性、形变和过渡。
- 笔记首页：笔记本宫格、全部笔记与未归档入口、新建笔记本、快速新建笔记；二级列表提供排序与长按多选。
- 笔记本详情：创建、重命名、删除确认、笔记数量与文字量、排序与手动拖动排序。
- 笔记编辑页：Header 选择笔记本、标题、完整富文本、表格、标题折叠、自动保存、会话内撤销重做。
- Room 3 本地笔记库：笔记本、笔记、FTS5、附件、历史版本；设置走独立 DataStore。
- 结构化 JSON 文档已定稿全部块类型；回收站 30 天清理走启动补扫与周期性后台任务。
- 所有笔记只保存结构化 `NoteDocument`；Markdown 快捷输入可在设置中关闭，只处理本次键盘输入，自动格式化可单独撤销。
- 搜索支持标题与正文、笔记本筛选、匹配片段高亮、持久化最近搜索和清空；FTS5 连续中文子串已通过真机数据库验收，回收站内容不参与搜索。
- “我的”已提供回收站入口；回收站支持删除元数据、原笔记本展示、恢复、永久删除、清空和多选，启动补扫与延迟执行的周期任务共同清理过期内容和未引用附件。
- 当前编辑界面复用同一层全屏背景画布，系统栏、Header 与底部工具区下方不再叠加页面底色；支持默认背景与单篇覆盖、四款内置纸张、实时预览及恢复继承。

- 图片支持相机/相册块级插入、缩放旋转和移动、删除替换复制及前后层级；纸面贴纸与微型胶囊，接入自动保存和撤销重做。

- 阅读模式：笔记本按当前顺序连续阅读，编辑页单篇阅读；实际测量分页、整块媒体、目录、页码、进度、编辑往返与背景跟随。

- 图片导出：P08 文件预览、短笔记单图与长笔记分页、固定背景快照、保存相册及系统分享。

- 平板多栏、完整“我的”入口、真实统计、本地占用与缓存清理、持久化外观及阅读排版设置。

尚未开始：

- Agent 单时间线、分层记忆与笔记工具按 S11 继续交付。

## 3. 总顺序

```text
S1 设计系统补齐
 → S2 本地数据层
 → S3 笔记本与普通文字笔记（含完整富文本）
 → S4 Markdown 与单向转换
 → S5 回收站与搜索
 → S6 笔记背景
 → S6.5 统一笔记模型与 Markdown 快捷输入
 → S7 图片基础插入与变换
 → S8 阅读模式
 → S9 导出图片
 → S10 平板多栏、我的、统计与外观（下一优先）
 → S11 Agent 单时间线、记忆与笔记工具 （功能清单第二阶段）
 → S12 抠图、贴纸、环绕布局、画笔    （功能清单第三阶段）
 → S13 MCP、Skill、Linux            （功能清单第四阶段）
```

约束：

- 未完成 S1 时不铺新业务页，避免每个页面私有骨架、浮层和 Header。
- S2 的文档模型按完整富文本一次性设计；S3 编辑器按“可编辑正文 → 样式与清单 → 表格 → 标题折叠”增量实现。
- S6.5 必须先于 S7 完成；图片、阅读、导出和 Agent 只面向统一的结构化笔记，不增加笔记类型分支。
- 图片、贴纸、画笔的 UI 分别在 S7 / S12，但 S2 就要留下对应块类型，避免后期改存储。
- 统计、存储占用、外观中的主题与辅助功能不阻塞笔记闭环，放到 S10；默认背景选择在 S6 先做最小设置入口。

## 4. 切片详情

### S1 设计系统补齐

**状态：** 已完成（2026-08-27）。

**目标：** 后续页面只组公共组件，不再复制玻璃材质、Header 或浮层。

**交付：**

- `XNotePageScaffold` 接入系统栏、Toast Host、页面级加载/错误，以及顶部/底部 `XNoteProgressiveBlur`。
- `XNoteHeader` 支持左侧返回、居中标题、右侧 0–2 个功能按钮；无右侧按钮时保留等宽占位。一级目的地继续用当前外壳 Header（标题 + 搜索）；普通二级页面走标准 Header，编辑页使用笔记本归属胶囊与撤销、重做、更多组成的 EditorHeader。
- `XNoteDialog`、`XNoteDrawer`、`XNoteToastHost`、`XNotePopup`、`XNoteDropdownMenu`。
- `XNoteLoadingState`、`XNoteEmptyState`、`XNoteErrorState`。
- 编辑器格式工具栏组件 `XNoteRichTextToolbar` 先定 API 与视觉，S3 再接到文档命令。

**不做：** 背景选择器、笔记画布、业务数据。

**验收：** 用笔记首页和两个占位页验证 Progressive blur、浅色/深色、减少动画、平板与手机；无页面私有圆角或私有按钮材质。

### S2 本地数据层

**状态：** 已完成（2026-08-27）。

**目标：** 本地笔记库可读写，搜索和回收站有表结构，附件有目录约定。

**工程约定：**

- 持久化使用 Room 3（`androidx.room3`）与 `BundledSQLiteDriver`。系统 SQLite 未编译 FTS5，因此必须打包 bundled SQLite。
- 全文检索使用 FTS5；索引前将连续 CJK 字拆成单字短语，使「笔记本」能命中「我的笔记本」。分词策略在 S5 验收时验证。
- 笔记正文存为自有 JSON 文档，不把 HTML 或 Markdown 当作源格式。
- 附件（图片、贴纸、画笔）放在应用私有文件目录，库中只存稳定 ID 与元数据。
- 设置（默认背景、主题等）与笔记库分开存储。
- 回收站清理用应用启动补扫 + 系统允许的后台任务，不承诺第 30 天的精确时刻。

**交付：**

- 实体：笔记本、笔记、文档块、附件、历史版本、设置。
- 笔记状态：正常 / 回收站；`deletedAt`、剩余保留天数的计算。
- 未归档：`notebookId == null`。
- 历史版本：第一版只服务 Agent 润色等原子改写前的撤回，不提供通用版本浏览。
- 纯文本抽取：供搜索、摘要、字数统计复用。
- 领域规则的单元测试（删除笔记本、恢复归属、文档有效性、字数口径）。

**块类型（S2 一次定稿）：**

```text
Note
├─ TextBlock      # 段落、标题、清单、检查清单、引用、对齐、高亮
├─ TableBlock     # 表格；单元格只含文字与行内样式
├─ ImageBlock     # S7 才提供编辑 UI
├─ StickerBlock   # S12
└─ DrawingBlock   # S12
```

**不做：** 界面、假数据层长期驻留、云同步。

### S3 笔记本与结构化文字笔记

**状态：** 已完成（2026-08-27）。

**目标：** 用户可以建立笔记本、写下完整富文本笔记、自动保存、删除到回收站。

**交付页面：** P01 笔记首页、P02 笔记本详情、P03 笔记编辑页（文字与表格，无图片入口）。

**产品规则：**

- 在“全部笔记”或未归档下新建 → 未归档；在某笔记本内新建 → 属于该笔记本。
- 首页：按笔记本名称和笔记数展示自适应宫格，集合入口进入二级笔记列表；标题/摘要/时间/所属笔记本、空状态与长按多选位于列表层。
- 笔记本：创建、重命名、删除确认；笔记数量与文字量；创建时间 / 更新时间 / 标题排序；手动拖动排序。
- 删除笔记本：笔记本记录立即永久删除；其下笔记全部进入回收站，并快照“原笔记本名称”仅供展示；恢复后 `notebookId` 为空。
- 删除空笔记本：直接消失，回收站无条目。
- 编辑页：标题在正文顶部，其下显示最近一次成功保存的日期（新建时即创建日期）；Header 中部为笔记本归属胶囊，右侧为撤销、重做与更多；底部为五入口胶囊、展开式格式检视器和表格情境条。
- 自动保存；撤销重做作用于当前编辑会话，不写入历史版本表。
- 多选动作：移入回收站、移动到笔记本。

**富文本范围（S3 必须做完）：**

1. 段落样式：正文、标题、小标题、等宽。笔记标题是独立字段，正文不再提供与标题重复的 Title 样式。
2. 行内样式：粗体、斜体、下划线、删除线、链接、高亮。
3. 结构：无序（圆点 / 虚线）、有序、检查清单、引用、多级缩进。
4. 对齐：左、中、右。
5. 表格：默认 2×2；增删行列；单元格仅文字与行内样式，不能嵌图片。
6. 标题与小标题可折叠。

**内部顺序：** 先打通标题 + 正文 + 保存 + 列表，再接样式与清单，再接表格，最后接折叠。

**不做：** 图片/贴纸/画笔入口、Markdown 快捷输入、阅读、导出、背景选择、Agent。

**验收：** 冷启动后数据仍在；删除笔记本后笔记只出现在回收站数据中（S5 才做回收站页，S3 可用调试入口或仓库查询证明恢复规则）；字体放大与减少动画下编辑器仍可用。

### S4 Markdown 与单向转换

**状态：** 已完成（2026-08-27）。

**目标：** 纯文字（含表格）的普通笔记可永久转为 Markdown；Markdown 笔记可编辑和预览。

**交付页面：** 原 P04 Markdown 笔记页；该独立页面将在 S6.5 移除，后续页面编号以功能清单为准。

**已交付：**

- 存在图片、贴纸或画笔块时禁用转换；表格、清单、引用和检查清单允许转换。
- 转换前写入历史版本；转换后进入 Markdown 编辑模式且不可转回。
- 按块顺序生成 Markdown 原文，支持编辑、确认保存、结构化预览和返回编辑。

该切片记录已经完成的仓库基线，不再代表最终产品形态；S6.5 负责完整替换，S7 及以后不得继续扩展双模式能力。

### S5 回收站与搜索

**状态：** 已完成（2026-08-27）。

**目标：** 删除可恢复，标题和正文可检索。

**交付页面：** P13、P16。

**回收站：**

- 列表展示标题、删除时间、剩余天数、原笔记本名称（若有）。
- 恢复、永久删除、清空、多选。
- 恢复时：原笔记本已不存在（含删除笔记本带入回收站的笔记）→ 未归档；若用户删除单篇且原笔记本仍在 → 回到原笔记本。
- 不参与普通列表、搜索、阅读、统计和 Agent Tool。
- 满 30 天后在启动补扫或后台任务中清理，并删除未被引用的附件。

**搜索：**

- 手机：独立全屏搜索页。
- 平板：在笔记列表栏顶部展开搜索框，结果仍按 P13 的信息结构展示。
- 标题与正文、按笔记本筛选、匹配片段高亮、最近搜索与清空。
- 回收站不参与。

**验收：** 中文连续子串（如“笔记本”命中“我的笔记本”）必须可用；若 FTS 分词导致漏检，S5 内改抽取或 tokenizer，不留到后续切片。

### S6 笔记背景

**状态：** 已完成（2026-08-27）。

**目标：** 两级背景规则在笔记编辑中生效，并可由阅读和导出复用。

**交付：**

- `XNoteNoteSurface`、`XNoteBackgroundPicker`。
- 外观设置中的默认背景入口（P24 的背景子集，可先从“我的”进入，S10 再补全其余外观项）。
- 编辑页更多菜单：更换专属背景 / 使用默认背景；影响范围文案为“仅当前笔记”。
- 背景选择器仅展示四款内置预设，不提供图片导入或其他自定义背景入口。

**内置预设：** 纯白纸（初始默认、无纹理）、浅灰纹理（细密纸纤维）、横线纸、方格纸；四款均随浅色/深色主题切换纸色与纹理对比度。

**不做：** 导出合成（S9）、阅读模式切换背景（S8 接入同一渲染规则）。

### S6.5 统一笔记模型与 Markdown 快捷输入

**状态：** 已完成（2026-09-08）。S7 的硬前置。

**目标：** 每篇笔记只使用一个结构化 `NoteDocument` 作为正文事实源；Markdown 仅作为输入快捷语法和导出边界，不再形成独立笔记类型、编辑页或预览状态。

**领域与数据收敛：**

- 删除领域层和页面层的 Markdown 笔记类型分支，`Note.document` 变为必需字段，不再长期保存 `markdownText`。
- 删除永久“转换为 Markdown”入口、确认弹窗、专用编辑/预览页面、专用撤销栈和只为模式转换存在的规则。
- 搜索、摘要、统计、背景、回收站、阅读、导出和 Agent 只消费统一文档接口。
- 富文本到 Markdown 的序列化能力可以保留为导出器，但不得改变笔记的源文档或类型。
- 开始实现前确认是否存在必须保留的外部用户数据：存在时将已有 Markdown 内容一次性解析进 `NoteDocument` 并验证迁移；不存在时执行全仓库协调式模型变更，不保留运行时兼容分支。

**快捷输入设置：**

- 在“我的 → 外观、辅助功能与编辑”增加“Markdown 快捷输入”开关，默认开启，说明文案明确其只影响之后的键盘输入。
- 设置通过现有 DataStore 持久化；关闭后所有 Markdown 字符按普通文本输入。
- 切换开关不得回扫、转换或恢复已有正文。

**识别与编辑规则：**

- 编辑器先把本次输入写入内存文档；仅当输入法不处于组合态、设置已开启且本次编辑形成明确触发符时，才调用纯函数快捷规则引擎。
- 块级规则只检查当前文字块段首，并在完整前缀后的空格输入完成时触发；行内规则只检查本次闭合标记覆盖的最小范围。
- 表格单元格仅允许行内规则，不应用标题、列表或引用等块级规则。
- 多行粘贴默认保留原文；完整 Markdown 文档解析属于未来显式导入流程，不与实时快捷输入共用触发条件。
- 无法无损映射、不完整、有转义或存在歧义的输入保持原字符，不猜测用户意图。
- 规则按“检查清单 → 列表 → 引用/标题 → 行内样式”的明确优先级执行，避免 `- [ ] ` 被无序列表规则提前消费。
- 行内规则优先识别较长分隔符，星号和下划线不得匹配单词内部字符；兼容样式可以嵌套，无法确定边界时延迟识别或保留原文。
- 自动格式化单独进入撤销历史：第一次撤销恢复原始 Markdown 字符，第二次撤销才继续回退此前输入；重做保持相同边界。
- 每次识别和结构变更后必须保持光标、选择区、输入焦点和自动保存版本一致。

**映射：** 只实现第 6 节标记为“实时”的语法；不以“完整 Markdown/CommonMark/GFM 兼容”对外描述。

**验收：** 覆盖中文输入法组合态、转义字符、未闭合标记、嵌套行内样式、表格单元格、撤销重做、关闭设置、返回/切后台落盘和进程重启；任何失败都不得破坏原始输入。

## 6. Markdown 快捷输入映射与边界

笔记标题始终由独立标题输入框编辑。下表只描述正文和表格单元格中的快捷输入，不承诺完整 Markdown 兼容。

| 用户输入 | 结构化结果 | 实时识别 | 触发与边界 |
| --- | --- | --- | --- |
| `# ` | 正文标题 | 是 | 仅文字块段首，输入尾随空格后触发 |
| `## ` | 正文小标题 | 是 | 仅文字块段首，输入尾随空格后触发 |
| `**文字**` 或 `__文字__` | 粗体 | 是 | 键入闭合标记后处理最小匹配范围 |
| `*文字*` 或 `_文字_` | 斜体 | 是 | 不匹配单词内部标记或未闭合标记 |
| `~~文字~~` | 删除线 | 是 | 键入闭合 `~~` 后触发 |
| `==文字==` | 高亮 | 是 | XNote 扩展语法，键入闭合 `==` 后触发 |
| `[文字](url)` | 链接 | 是 | 键入闭合 `)` 后触发；地址为空或括号未闭合时保留原文 |
| `- ` | 虚线无序清单 | 是 | 仅段首；优先级低于检查清单 |
| `* ` 或 `+ ` | 圆点无序清单 | 是 | 仅段首 |
| `1. ` | 有序清单 | 是 | 仅段首；起始数字用于识别，不写入固定序号 |
| `- [ ] ` / `- [x] ` | 未完成 / 已完成检查项 | 是 | 仅段首，先于无序清单识别 |
| `> ` | 引用 | 是 | 仅段首 |
| 围栏代码前缀 | 整段等宽 | 暂不实现 | 当前模型没有围栏范围和语言属性 |
| 行内反引号 | 行内代码 | 否 | 当前行内模型没有代码属性，保持原文 |
| 前导空格或 Tab | 多级缩进 | 否 | 输入歧义较大，继续使用工具栏或键盘缩进命令 |
| `<u>文字</u>` | 下划线 | 否 | HTML 不是通用 Markdown 快捷语法，使用工具栏 |
| 管道表 | 表格块 | 否 | 需要跨行解析，只能由未来显式导入流程处理 |
| `![说明](url)` | 图片块 | 否 | 不在输入过程中发起网络下载或创建附件 |
| H3–H6、分隔线 | 无对应结果 | 否 | 当前文档模型不提供对应结构，保持原文 |
| 对齐、标题折叠 | 无对应语法 | 否 | 只通过格式工具栏操作 |

所有规则都必须识别反斜杠转义，并允许粗体、斜体、删除线和高亮以文档模型可表达的方式组合；发生冲突时宁可保留用户原文，也不做有损猜测。

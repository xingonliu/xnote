## 1. 产品定位

XNote 是一款面向 Android 13 及以上手机和平板的本地优先笔记应用，核心由统一的结构化笔记编辑、图片及贴纸内容、阅读模式、全文搜索和可操作笔记的 Agent 组成。Markdown 只作为常用格式的快捷输入语法和可选导出格式，不构成独立笔记类型或存储格式。

应用采用本地笔记库作为主要数据源。Agent 通过受统一权限约束的工具读取、搜索、创建、修改和删除笔记，不会默认把整个笔记库加入模型上下文。Agent 只提供一条持续存在的对话时间线，使用当前片段原文、历史片段摘要、长期画像和文档记忆组成分层上下文；完整规则以 Agent 记忆与上下文架构文档为准。

## 2. 一级导航

### 2.1 手机端

底部导航直接使用 AndroidLiquidGlass 官方 catalog 的 `LiquidBottomTabs` / `LiquidBottomTab`，包含三个一级目的地：

1. 笔记
2. 贴纸库
3. 我的

Agent 作为底栏右侧独立圆形按钮，与左侧 tabs 共用官方示例的 64 dp 高度，并复用玻璃外壳、裁剪和按压高光，使用同尺寸图标及下方 Agent 标签；点击进入独立对话页，顶部返回与系统返回恢复进入前的页面。搜索由 Header 入口进入全屏搜索页。贴纸库右下角提供与首页新建按钮同尺寸、同材质的相机入口，拍照后进入抠图创作。

### 2.2 平板端

底部导航转换为左侧导航栏，保留相同的一级目的地，Agent 作为独立按钮打开可返回的对话页。

笔记区域优先使用多栏布局：

```text
侧边导航 | 笔记本列表 | 笔记列表 | 笔记内容
```

标准字号下，笔记区在 840 dp 起使用多栏、1200 dp 起完整展开四栏；阈值随应用与系统字体放大提高。中等宽度在打开正文时收起笔记本栏，窄窗口使用单栏导航。栏目共享当前笔记、排序与编辑会话，切换笔记前完成保存，调整窗口保留草稿和撤销记录。

Agent 区域以当前选中会话的时间线为主体，可以按窗口宽度增加上下文、记忆、笔记范围或工具详情面板。搜索入口在笔记列表顶部展开为搜索框。

## 3. 功能清单

### 3.1 笔记本

- 创建、重命名和删除笔记本；首页长按即可管理，无需进入详情。
- 首页显示最近编辑笔记的标题或摘要，支持保存颜色和图标；右上角管理入口支持拖拽排序和无障碍上移/下移。
- 顶部圆角分组包含全部笔记、未分类（灵感收集箱）、最近删除及各自数量。
- 查看笔记本内的全部笔记。
- 显示笔记数量和文字量。
- 支持笔记手动排序。
- 支持按创建时间、更新时间和标题排序。
- 从笔记本进入阅读模式。
- 笔记可以不属于任何笔记本，作为未归档笔记存在。
- 删除笔记本后，笔记本立即永久消失，不能从回收站恢复。
- 首页删除时可将活动笔记移到未分类并保留搜索，或连同笔记移入回收站并保留原笔记本名称快照。已在回收站的笔记保留原删除时间，不因删除笔记本重置保留期限。
- 这些笔记从回收站恢复后变为未归档笔记。
- 删除空笔记本时直接消失，回收站不产生条目。

### 3.2 笔记

- 创建笔记。
- 编辑标题和正文。
- 为单篇笔记设置专属背景，或恢复继承默认背景。
- 选择或更改所属笔记本。
- 自动保存编辑内容；输入法仍处于组合态的每次文本变化也必须立即进入内存文档，返回页面或应用进入后台前强制完成落盘，不能出现界面已显示但重开后丢失末字的情况。
- 撤销和重做。
- 导出笔记为图片。
- 移入回收站。
- 从回收站恢复。
- 单篇笔记恢复时，若原笔记本仍存在则回到原笔记本；若原笔记本已被删除则变为未归档。
- 保存 Agent 润色等原子改写前的必要历史版本。第一版不提供通用版本浏览。

### 3.3 笔记文档与编辑能力

所有笔记使用同一种结构化文档模型，支持：

- 文字块，对齐 Apple Notes 的编辑能力：正文、标题、小标题、等宽；粗体、斜体、下划线、删除线、链接、高亮；圆点/虚线无序清单、有序清单、检查清单、引用、多级缩进；左/中/右对齐；标题与小标题可折叠。
- 表格块：单元格只含文字与行内样式，不能嵌套图片或贴纸；插入表格或增删行列后，当前选择和输入焦点必须跟随到仍然有效的目标单元格或相邻正文块。
- 图片块。
- 贴纸块。
- 图片和贴纸的缩放、移动和旋转。
- 图片和贴纸的前后层级调整。
- 图片嵌入文字、文字环绕和浮于文字上方。
- Agent 润色。
- 携带当前笔记进入 Agent 对话。

笔记标题是独立字段，显示在正文顶部。正文段落样式中的“标题”和“小标题”分别表示正文一级标题与正文二级标题，不替代笔记标题。

正文选区由编辑器统一管理，长按选中文字后可拖动起止手柄跨段落、跨表格单元格选择，拖至视口边缘时自动滚动。“全选”覆盖正文文字（包括折叠段落和表格），标题仍独立编辑。复制按段落换行、表格同行单元格用制表符分隔；剪切、删除、粘贴替换、撤销及格式工具栏共用这份选区。连续文字段落在替换后合并边界；跨图片或表格时保留媒体和表格结构，仅替换选中文字。图片环绕文字也接入相同选区。

纸面空白、续写区域和编辑页点击控件关闭默认涟漪，点击定位与输入功能保留。选区高亮用于表示实际选中文字。

笔记始终采用块结构保存内容，JSON 文档是正文的唯一事实源；不同时保存另一份 Markdown 或 HTML 原文：

```text
Note
├─ TextBlock
├─ TableBlock
├─ ImageBlock
└─ StickerBlock
```

### 3.4 Markdown 快捷输入

Markdown 是编辑器中的可选输入快捷方式。识别成功后，编辑器移除语法标记并直接写入标题、列表或行内样式等结构化属性；笔记仍留在同一个编辑页，图片、贴纸和表格能力不受影响。

- “我的 → 外观、辅助功能与编辑”提供“Markdown 快捷输入”开关，初始默认开启。
- 开关只影响之后的键盘输入，不回扫或改写已有内容。
- 块级语法只在文字块段首输入完整前缀并键入空格后触发，例如 `# `、`## `、`> `、`- `、`1. ` 和 `- [ ] `。
- 行内语法只在用户键入闭合标记后触发，例如 `**粗体**`、`__粗体__`、`*斜体*`、`_斜体_`、`~~删除线~~`、`==高亮==` 和 `[文字](https://example.com)`。
- 输入法处于组合态时只更新内存文档，不执行识别；组合结束后也不得扫描本次编辑范围之外的旧文本。
- 只解析本次编辑影响的当前文字块或表格单元格，不在每次输入时重新解析整篇笔记。
- 表格单元格允许行内快捷语法，不允许标题、列表、引用等块级转换。
- 不完整、有转义、存在歧义或目标文档模型无法无损表达的写法保留为普通字符。
- 多行粘贴默认保留原文，不静默转换整篇内容；以后如提供 Markdown 导入，应作为显式、可预览和可取消的独立流程。
- 自动格式化作为独立的撤销步骤记录；转换后的第一次撤销恢复用户刚刚输入的 Markdown 字符，下一次撤销才继续回退普通输入。
- 下划线、对齐和标题折叠没有通用 Markdown 对应语法，只能通过格式工具栏操作；`==高亮==` 是 XNote 明确支持的扩展语法。
- 当前文档模型只有整段等宽样式，围栏代码可切换整段样式，但行内反引号在增加独立行内代码属性前保持原文。
- 管道表需要跨行确认结构，不参与实时快捷输入；未来仅在显式 Markdown 导入中处理。

完整映射和识别边界以开发顺序文档第 6 节为准。

### 3.5 图片添加与编辑

笔记编辑页底栏提供“插入”按钮。点击后打开相册、相机与表格气泡菜单，图片来源包括：

1. 相机
2. 相册
3. 贴纸（贴纸库交付后才显示该入口）

图片支持：

- 拍照或通过系统相册选择。
- 缩放、旋转和移动。
- 在纸面上直接拖动，使用右下角复合手柄或双指同步缩放和旋转。
- 调整前后层级。
- 删除、替换和复制。
- 发起抠图。
- 将抠图结果直接插入笔记或保存为贴纸。

手机和平板均使用插入气泡选择图片来源，使用选框、控制柄与微型胶囊操纵图片。Liquid Glass 浮层在同一个 Compose Host 内绘制，并位于正文捕获层之外。

### 3.6 抠图

- 对相机照片和相册图片执行抠图。
- 显示模型下载、加载和处理进度。
- 支持原图、蒙版和透明背景结果预览。
- 支持重新处理。
- 支持简单的蒙版添加与擦除修正。
- 保存为带透明通道的 PNG 或 WebP。
- 保存到贴纸库或直接插入当前笔记。

模型方向根据最终交互选择：

- 一键自动识别主体：RMBG 类型模型。
- 点击或框选目标：MobileSAM、EdgeSAM 类型模型。
- 组合方式：自动生成初始蒙版，再由用户交互修正。

模型的商业许可证、包体、内存、耗时和端侧算子兼容性需要单独验证。

### 3.8 笔记导出

- 将笔记导出为图片。
- 短笔记可以导出为单张图片。
- 长笔记按页面导出为多张图片，避免生成超大 Bitmap。
- 导出内容应与阅读或预览排版一致。
- 导出结果必须包含当前笔记解析得到的背景，并覆盖完整导出画布。
- 多页导出在任务开始时固定同一个背景快照，不能因导出期间设置变化而出现跨页差异。
- 图片和贴纸需要合成到最终结果。
- 支持预览、保存和调用系统分享。
- 可选的 Markdown 文件导出只生成派生文件，不改变笔记类型或源文档；下划线、高亮、对齐、折叠和媒体布局等非通用语义必须在导出预览中明确其降级规则。

### 3.9 阅读模式

- 从笔记本页面进入阅读模式。
- 按笔记本当前顺序呈现笔记。
- 每篇笔记必须从新页开始。
- 长笔记允许跨越多个页面。
- 图片和贴纸块不从中间切割；剩余空间不足时整体移动到下一页。
- 支持上一页、下一页、页码和阅读进度。
- 显示当前笔记标题。
- 支持打开笔记目录并跳转到指定笔记。
- 支持从阅读模式进入当前笔记的编辑页。
- 每篇笔记使用自己的专属背景；未设置专属背景时使用设置中的默认背景。
- 屏幕尺寸、字体缩放、横竖屏或窗口大小变化时重新分页。

分页结果是基于当前排版环境生成的派生数据，不作为固定页码永久写入数据库。阅读时完整展开标题下的内容，但不更改笔记保存的折叠状态；超过整页的媒体等比缩小以完整展示。表格按文字行续排。重新分页与编辑返回时，以笔记和正文位置恢复阅读锚点。

### 3.10 用户搜索

- 搜索笔记标题和正文。
- 按笔记本筛选。
- 显示匹配片段并高亮匹配文字。
- 点击结果进入对应笔记。
- 保存最近搜索记录。
- 支持清空搜索记录。
- 回收站内容不参与普通搜索。

手机端点击独立搜索按钮进入全屏搜索页。平板端点击搜索按钮后，在笔记列表栏顶部展开搜索框。

### 3.11 Agent 搜索工具

Agent 通过 `note_search` 查询权限范围内的笔记及其内容：

```text
note_search(
    query,
    notebookId?,
    limit?,
    cursor?
)
```

搜索结果包含：

- 笔记 ID。
- 当前内容版本或内容哈希。
- 标题。
- 所属笔记本。
- 匹配片段。
- 更新时间。

`note_search` 只返回匹配摘要。Agent 需要完整内容时继续调用 `read`。

权限与安全要求：

- 请求批准先批准具体搜索调用；完全隐私禁止搜索；完全访问可自动检索。
- 不返回无权限笔记的标题、摘要、匹配数量或其他元数据。
- 回收站内容默认不参与 Agent 搜索。
- 第一版使用本地全文搜索；向量或语义检索作为后续能力。
- 中文内容需要验证连续文字搜索和分词策略。

### 3.12 Agent 对话

- 对话页直接展示一条持续存在的时间线。
- 多轮对话和流式回复。
- 停止生成和取消正在运行的 Agent Loop。
- 发送文字，以及图片、PDF、纯文本和 Markdown 附件；发送前校验模型能力，不自动导入笔记库。
- Agent 返回文字及纯文本/Markdown 文件，支持预览、保存和分享；S11 不接入独立图片生成服务。
- 展示 Tool Call、工具参数、执行状态和结果。
- 展示错误、权限请求和用户确认。
- 保存对话历史。
- 内部按 30 分钟无新交互、片段容量上限或用户明确切换话题划分片段；片段只用于压缩和回溯。
- 已关闭片段由无工具权限的大模型函数生成结构化摘要和短文，摘要失败不影响原始记录。
- 长期画像只保存重要的原子事实和可学习偏好，使用来源、优先级、替换链和遗忘标记管理更新。
- 笔记作为独立文档记忆进入统一上下文组装层，不把正文复制进会话摘要或画像。
- 默认使用当前片段原文、当前画像、用户显式附加内容、相关文档记忆、相关历史摘要和少量近期摘要组装上下文，不固定注入 5–10 篇摘要。

运行交互：

- 运行中发送默认补充当前任务；另可加入队列，队列支持编辑、删除、排序。
- 正常完成后继续队列；等待授权或冲突处理时不启动下一项；停止、失败则暂停队列。
- 未审阅 Diff 可保留，同篇再次修改累计到该篇审阅范围。
- 离开页面、切后台或锁屏后继续执行，系统通知展示状态与停止入口。
- 系统终止后保留内容和改动，重启标记中断，由用户选择继续；停止不自动回退已应用改动。

Agent Loop 需要支持：

- 最大循环次数。
- 超时和取消。
- 基于优先级和 Token 预算的上下文组装与裁剪。
- 工具结果大小限制。
- 工具失败处理。
- 重复调用防护。
- 应用异常退出后的必要恢复。
- `memory_search` 搜索历史片段摘要与安全消息片段。
- `memory_read` 分页读取指定历史片段的完整安全文本。

### 3.13 Agent 笔记工具

Agent 可以使用：

- `read`
- `note_search`
- `create`
- `write`
- `delete`

| 模式 | 执行规则 |
| --- | --- |
| 完全隐私 | 资料工具不可用；不自动读取笔记、画像和历史记忆。主动发送的文字与文件仍作为模型输入。 |
| 请求批准（默认） | 每次资料函数调用须在执行前批准；批准绑定运行、调用 ID、工具名、固定参数及权限版本。 |
| 完全访问 | 资料工具自动执行，仍校验参数、资源、选区、版本冲突和服务凭据。 |

只有一个全局权限模式。请求批准中的数据目标由该次调用参数确定；批准读取不授权写入，批准创建不授权后续读取。内置、记忆、文件和外部 Provider 共用执行关口。附加笔记仅提供引用元信息，不授予正文读取权限。

切换权限递增版本并使旧审批失效。已完成调用只重放合法结果，不能重复产生副作用；外部结果未知时仅核对原调用。审批弹窗只有允许本次与不允许，关闭窗口保持等待。

### 3.14 Agent 笔记改动与润色 Diff

- 支持润色全文或用户选择的文字，审阅统一按单篇进行。

- 获准的创建、修改和删除实时应用，并按单篇笔记展示待审阅 Diff；润色使用同一机制。
- 每篇独立全部接受或全部拒绝，范围是自上次审阅后全部未接受的 Agent 改动，允许跨多轮累计。
- 接受确认保留已应用改动；拒绝只撤销 Agent 改动，保留用户自己的编辑。
- Agent 应用前检查最新版本，不重叠修改可合并，同处冲突保留用户输入，重新读取并调整。
- 拒绝发现冲突时暂停整次回退，不部分写入；用户可保留当前内容，或让 Agent 基于最新内容调整。
- 删除立即移入回收站，对话保留删除卡片；接受保留删除结果，拒绝恢复；创建也按整篇审阅。
- 未审阅状态在退出、重启后保留；保存改动前版本及用户/Agent 来源，不用整篇旧快照覆盖用户后续编辑。
- 文字 Diff 以红色表示删除、绿色表示新增；文字块按段落或行定位，行内词级高亮；等宽段落优先行级比较。
- 首版 Agent 可编辑标题、富文本和表格，保留媒体、背景和归属；Diff 标记和审阅记录独立持久化，不写入正文。
- 最近一次已接受批次可在 30 天内撤回，仍做用户编辑冲突检查；回收站维持 30 天清理，永久删除后明确不可恢复。详见 S11 实施方案 D05–D06。

### 3.15 携带笔记进入 Agent 对话

- 编辑页提供独立的“与 Agent 对话”按钮。
- 点击后跳转到 Agent 对话页。
- 自动插入当前笔记卡片。
- 卡片显示标题、摘要、所属笔记本和修改时间。
- 消息上下文明确标记为“用户显式提供的笔记内容”。
- 发送时保存内容快照，笔记卡片绑定笔记 ID、版本和快照；附加引用不授予读取权。
- 附加笔记仅向模型发送 ID、快照 ID、版本、标题、更新时间和可选选区定位；正文通过 `read` 按需读取。统一 `read` 同时提供授权目录、笔记本内笔记和单篇正文读取。
- 读取最新版本同样遵守统一权限，明确区分快照与当前内容；编辑始终检查最新正文。
- 原笔记进入回收站后快照停止提供给模型，永久删除时清理关联快照。
- 用户显式附加笔记，为当前片段授予对该版本的临时读取权限；片段关闭后不自动延续。

### 3.16 Skill

- 安装、启用、禁用、更新和卸载 Skill。
- 显示 Skill 名称、来源、版本和能力说明。
- 第一阶段支持 `SKILL.md`、references 和 assets。
- 可执行脚本需要 Linux 沙箱，并在后续阶段开放。
- 脚本型 Skill 需要来源信任、权限清单、哈希或签名、网络限制和存储配额。

### 3.17 MCP

- 添加、编辑、启用、禁用和删除 MCP Server。
- 查看连接状态、能力和授权范围。
- 第一阶段支持远程 Streamable HTTP MCP。
- 后续通过 Linux 沙箱支持本地 stdio MCP。
- 支持用户授权、OAuth、超时、取消和工具审计。
- MCP 工具同样经过统一执行前审批，并检查服务凭据。

### 3.18 Linux 环境

- Linux 作为 Agent 的隔离工具执行环境存在。
- Agent Loop 保持在 Android 原生层，命令通过 Shell Tool 进入 Linux 环境。
- 支持查看安装状态、版本、磁盘占用和运行状态。
- 支持安装、修复、重置和停止环境。
- Shell 的网络、文件系统和执行权限单独管理。

### 3.19 统计

- 全部笔记文字量。
- 各笔记本文字量。
- 未归档笔记文字量。
- 笔记总数及包含表格、图片或贴纸的笔记数量。
- 图片和贴纸内容数量。
- 最近创建和修改的笔记。
- 后续支持按日、周和月展示写作趋势。

统计口径：

- 统计文字块和表格单元格中的可见文本；Markdown 快捷输入的语法标记在转换后不存在，不参与统计。
- 不统计标题和媒体文件名。
- 中文显示字符数，英文可以同时显示单词数。

### 3.20 回收站

- 删除笔记时写入删除时间并移入回收站。
- 笔记至少保留30天。
- 显示剩余保留天数。
- 因删除笔记本而进入回收站的笔记，列表中展示原笔记本名称快照。
- 支持恢复、永久删除和清空回收站。
- 支持多选操作。
- 单篇恢复时，原笔记本仍存在则回到原笔记本，否则变为未归档。
- 回收站只保存笔记，不保存笔记本；被删除的笔记本不能恢复。
- 回收站内容不参与普通列表、搜索、阅读、统计和 Agent Tool。
- 永久删除时清理不再被其他笔记或贴纸引用的附件。
- 后台清理任务不保证在第30天的精确时刻执行；达到期限后在系统允许的后台任务或下次应用启动时清理。

### 3.21 贴纸库

- 展示用户保存的全部抠图结果。
- 网格浏览、预览、搜索和排序。
- 重命名和删除贴纸库条目。
- 将贴纸插入当前笔记。
- 从相机或相册图片创建贴纸。
- 使用带透明通道的 PNG 或 WebP 保存。
- 删除贴纸库条目不会破坏已经插入笔记的贴纸实例。

### 3.22 Liquid Glass

Liquid Glass 用于：

- 底部导航栏。
- 平板侧边栏。
- 顶部工具栏。
- 浮动按钮。
- 悬浮操作胶囊。
- 同窗口弹层和悬浮面板的外壳。

内容卡片、列表行内操作、筛选与表单入口使用普通材质；`XNoteButton` 复用玻璃按钮的完整按压形变与回弹，采用轻中性填充、常态无描边、零投影及 12 dp 连续圆角，按压泛光从触点向外柔和衰减，等宽高图标按钮保持正圆。笔记编辑页及其工具栏、背景和图片面板维持现有外观与交互。

技术边界：

- 使用固定版本的 AndroidLiquidGlass `io.github.kyant0:backdrop:2.0.1`。
- Android 13（API 33）是最低支持版本，所有受支持设备统一启用完整背景采样、模糊、折射和色散效果。
- AndroidLiquidGlass 发布物不打包高层组件，因此固定采用官方 catalog 提供的组件源码；当前基线对应上游提交 `65ab177`。
- 手机 tabbar 直接使用官方 `LiquidBottomTabs` / `LiquidBottomTab`，悬浮按钮使用 `LiquidButton` 并保留其材质配方，内容区按钮使用 `XNoteButton`；两者共用交互实现；按钮几何固定为 XNote 紧凑控件的 40 dp 高度与 8 dp 水平内边距。
- Bottom Tabs 正文避让令牌为 96 dp，玻璃容器与右侧 Agent 按钮高度统一为官方示例的 64 dp、选中内容层与滑块为 56 dp、内容内边距为 4 dp；底部间距保持 16 dp 并叠加系统导航栏安全区。玻璃采样完整页面内容，容器底色不透明度固定为官方 40%，按压全区域白光为 0.08、无 Shader 兜底为 0.25；滑块路径切割出的图标和文字使用主题主色。
- 滚动列表与设置使用 AndroidLiquidGlass catalog Progressive blur，随滚动边界显隐；抠图、贴纸库与预览、分页阅读和导出不显示边缘遮罩，按实际控件与安全区避让。
- 后续组件先核对官方 catalog；已有 `LiquidToggle`、`LiquidSlider` 等实现时直接采用，只有不存在对应组件时才创建基于 AndroidLiquidGlass 的项目级适配。
- 项目级适配不得重复实现库已有的 Backdrop、Lens、Blur、Vibrancy、高光或阴影能力；当前只为 catalog 缺少的 Panel 与竖向 Navigation Rail 保留适配层。
- 被录制的页面内容和玻璃 Overlay 分层，玻璃组件不进入自身的背景录制。
- 需要玻璃效果的浮层优先在同一个 Compose Host 内绘制，不承诺跨 Window 的 Popup 或 Dialog 背景采样；Popup 与下拉菜单按触发控件的真实边界定位，在安全区内自动翻转，宽度随单行内容确定，仅面板执行锚点缩放与淡入淡出。Drawer 的全屏遮罩以 300 ms 独立淡入，不随面板从底部或侧边滑入；点击遮罩即可关闭。
- 第一阶段完整支持圆形、胶囊和圆角矩形。
- 普通自定义 Shape 可以用于裁剪和 Tint，但不默认承诺基于精确 SDF 的透镜法线。
- 文本和图标作为前景内容绘制，不进入背景模糊层。
- 尊重减少动画和高对比度设置，同时保留完整 Liquid Glass 材质。

### 3.23 笔记背景

- 笔记背景面板提供默认开启并持久保存的自动深浅模式开关，适用于所有编辑页；按编辑画布实际可见的居中裁切区域进行 64 × 64 取样，上下各约 25% 区域的像素权重最高为中间的 1.5 倍，分区交界平滑过渡；按加权主色的感知亮度选择主题，画布尺寸变化后重新判断。关闭、内置背景或图片不可读取时沿用应用外观；手机同步系统栏，平板只改变编辑栏。

笔记背景采用“全局默认背景 + 单篇笔记专属覆盖”的两级规则：

```text
当前笔记背景 = 当前笔记专属背景 ?? 设置中的默认背景
```

- 背景支持四款内置预设；编辑页可通过系统图片选择器导入或替换自定义图片，取消或失败保留原背景；遮罩不透明度使用 AndroidLiquidGlass 官方滑块在 0–100% 间实时调整并自动保存，替换图片保留数值。
- 内置预设固定为四款：纯白纸（初始默认、无纹理）、浅灰纹理（细密纸纤维）、横线纸、方格纸；浅色与深色主题使用各自的纸色和低对比纹理。
- 在“外观、辅助功能与编辑”中设置默认背景。
- 在笔记编辑页中，为当前单篇笔记更换专属背景。
- 背景选择界面必须明确显示影响范围为“仅当前笔记”。
- 选择“使用默认背景”时删除当前笔记的覆盖项，立即恢复继承当前默认背景。
- 修改默认背景会立即影响所有未设置专属背景的笔记，不覆盖已有的单篇笔记专属背景。
- 新建笔记初始继承默认背景，不复制当时的默认背景值，确保后续默认背景变化可以生效。
- 笔记编辑、阅读模式、润色 Diff 和导出预览使用同一背景解析规则。
- 背景归属于笔记；移动笔记所属的笔记本不会改变其专属背景或继承状态。
- 在笔记编辑页中，背景是全屏页面背景，并连续延伸到系统栏、Header 与底部工具区下方；应用导航、弹层及其他 Overlay 仍独立绘制在它上方。
- 单篇笔记覆盖项保存稳定的内置背景标识或图片附件 ID；图片存入应用附件目录，重启和相册原图删除不影响背景，回收站保留引用。

导出规则：

- 导出笔记、阅读分页和长图时必须绘制解析后的背景。
- 背景覆盖完整输出尺寸，包括正文留白和分页边距，不导出 Header、工具栏、按钮或 Liquid Glass Overlay。
- 导出预览与最终文件使用同一背景渲染器、裁剪规则、缩放规则和色彩模式。
- 如果背景资源在导出开始后发生变化，当前导出继续使用任务开始时的背景快照，下一次导出再使用新背景。

### 5.3 P03 笔记编辑页

顶部工具栏：

- 返回。
- 中间留空。
- 独立的透明玻璃撤销按钮，按历史记录启用。
- 更多菜单。

正文区域：

- 当前笔记解析后的专属或默认背景。
- 可编辑的笔记标题。
- 标题下显示最近一次成功保存的日期，新建时显示创建日期，格式为 `yyyy年M月d日`。
- 文字块。
- 表格块。
- 图片块。
- 贴纸块。

底部工具区：

更多菜单：

### 5.10 P10 Agent 对话页

顶部区域：

- 导航名称固定“Agent”，页面 Header 无标题。
- 复用公共 Header，左侧依次为返回、历史记录，右侧新会话与更多，按钮统一 40 dp。历史记录 Popup 展示会话标题与最近活动时间，点击条目加载该会话；新会话立即隐藏原消息并显示空消息引导，原消息保留在历史中。
- Header 下方的顶部渐变遮罩使用消息正文采样，随实际消息列表的滚动状态显示，回到列表起点时淡出；消息顶部留白覆盖遮罩高度。
- 更多菜单包含全部笔记改动、任务队列、模型配置、记忆与画像及后台通知入口。
- 运行时通过输入框右下角停止任务，暂停后的恢复操作位于输入区上方；工具详情也提供所属运行的停止或继续入口。

消息区域：

- 参照提供的 iMessage 图适配：用户右侧蓝色气泡，使用按可见聊天视口定位的不透明蓝色渐变与白色正文；Agent 结束语左侧浅灰／深灰半透明磨砂气泡，独立背景采样与 12 dp 模糊。气泡使用独立 14 sp 字号、18 sp 行高，Tabbar 保持 12 sp，随字体设置缩放；主体使用最大 20 dp 圆角，曲线尾巴外伸 6 dp、下延 4 dp，宽度随正文收缩。60 秒内相邻的同片段已完成纯文字用户消息成组，同一结束语多行也成组，仅组末显示尾部，主体外壁及正文对齐；附件、笔记快照和待处理状态打断用户分组，附件前正文无尾。详细参数与资料见 [Agent 气泡复刻说明](./XNote%20Agent%20气泡复刻说明.md)。
- 用户使用发送气泡；Agent 普通文字直接显示，只有 `finish_task` 结束语使用接收气泡，每个非空行单独成泡。长按文字或气泡可复制并查看时间。Agent 回复使用纯文本。
- 一个任务包含普通文字、工具调用和结束语。结束后过程默认折叠为用时、展开箭头和占满聊天区域扣除两侧间距后的下横线，下方保留结束语气泡；点击可展开完整过程。
- 完成任务必须独立调用 `finish_task`，summary 非空且最多 240 字，通常一两句，自然克制；普通文本不能完成任务，有待处理补充时继续处理。结束语工具在各权限模式下均可调用，不读取或修改资料。
- 新会话 Toast 显示前消费通知状态，切走页面再回来不会重复弹出。
- 笔记卡片。
- 图片和文件卡片。
- 气泡外独立工具调用记录使用左对齐、背景完全透明的胶囊，文字和图标适配主题，单行摘要超长省略，收起宽度上限与消息气泡一致；点击文字或箭头原位展开参数、结果、授权记录和笔记回执，展开内容使用聊天区域完整宽度。从聊天数据库恢复调用顺序。
- 错误和权限请求。
- 回到底部按钮仅在列表离开最新位置并能够向最新消息滚动时显示；内容未撑满或已经位于底部时隐藏，运行中显示律动点，空闲时显示下箭头。
- 低干扰的日期或片段时间分隔，不提供片段命名和管理。

输入区域：

- 文本输入。
- 添加图片或文件。
- 附件加号菜单提供笔记、图片和文件；支持图片、PDF、UTF-8 TXT／Markdown，发送前校验能力与容量，保留不支持或超限的草稿。
- 左侧附件加号、当前权限与范围摘要，右侧采用 Keyline Rounded Fill `send` 图标的 Liquid Glass 发送按钮；选区润色草稿显示范围提示。权限按钮按文字及箭头宽度收缩，展开锚定下拉菜单，选择后保存。
- 输入容器复用笔记编辑页菜单玻璃材质，位于底部安全区上方 16 dp，与 tabbar 共用下间距；玻璃采样聊天正文。Agent 页隐藏一级导航，菜单按安全区和键盘自适应，输入区连续跟随键盘高度。
- 操作成功、失败及临时说明使用公共 Toast。
- 右下角按钮在运行且空输入、没有待发文件时显示停止图标，点击停止任务；输入文字或添加待发文件后切回发送，运行中默认补充当前任务。消息立即保存并显示，当前响应及工具调用处理完毕后，在下一次模型请求前进入上下文。输入区上方保留暂停与恢复操作，运行中的队列从更多菜单进入；选区润色为独立任务，运行中可加入队列，队列可编辑、删除和排序。

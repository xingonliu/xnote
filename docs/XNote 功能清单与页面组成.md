# XNote 功能清单与页面组成

> 文档版本：v0.6
>
> 产品平台：Android 13（API 33）及以上的手机、平板
>
> 文档状态：功能与页面结构草案
>
> 配套规范：[XNote UI 设计规范](./XNote%20UI%20设计规范.md)
>
> 开发顺序：[XNote 开发顺序](./XNote%20开发顺序.md)

## 1. 产品定位

XNote 是一款面向 Android 13 及以上手机和平板的笔记应用，核心由笔记管理、普通笔记与 Markdown 编辑、图片及画笔内容、阅读模式、全文搜索和可操作笔记的 Agent 组成。

应用采用本地笔记库作为主要数据源。Agent 通过受权限和数据范围约束的工具读取、搜索、创建、修改和删除笔记，不会默认把整个笔记库加入模型上下文。

## 2. 一级导航

### 2.1 手机端

底部导航直接使用 AndroidLiquidGlass 官方 catalog 的 `LiquidBottomTabs` / `LiquidBottomTab`，包含三个一级目的地：

1. 笔记
2. Agent
3. 我的

搜索作为右侧独立按钮存在，点击后进入全屏搜索页面。

### 2.2 平板端

底部导航转换为左侧导航栏，保留相同的一级目的地和独立搜索入口。

笔记区域优先使用多栏布局：

```text
侧边导航 | 笔记本列表 | 笔记列表 | 笔记内容
```

Agent 区域优先使用会话列表与对话区双栏布局。搜索入口在笔记列表顶部展开为搜索框。

## 3. 功能清单

### 3.1 笔记本

- 创建、重命名和删除笔记本。
- 查看笔记本内的全部笔记。
- 显示笔记数量和文字量。
- 支持笔记手动排序。
- 支持按创建时间、更新时间和标题排序。
- 从笔记本进入阅读模式。
- 笔记可以不属于任何笔记本，作为未归档笔记存在。
- 删除笔记本后，笔记本立即永久消失，不能从回收站恢复。
- 该笔记本内的全部笔记移入回收站，并保留原笔记本名称快照仅供识别。
- 这些笔记从回收站恢复后变为未归档笔记。
- 删除空笔记本时直接消失，回收站不产生条目。

### 3.2 笔记

- 创建普通笔记。
- 编辑标题和正文。
- 为单篇笔记设置专属背景，或恢复继承默认背景。
- 选择或更改所属笔记本。
- 自动保存编辑内容。
- 撤销和重做。
- 导出笔记为图片。
- 移入回收站。
- 从回收站恢复。
- 单篇笔记恢复时，若原笔记本仍存在则回到原笔记本；若原笔记本已被删除则变为未归档。
- 保存必要的历史版本，用于模式转换和 Agent 润色后的撤回。第一版不提供通用版本浏览。

### 3.3 普通笔记模式

普通笔记是默认笔记类型，支持：

- 文字块，对齐 Apple Notes 的编辑能力：正文、标题、小标题、等宽；粗体、斜体、下划线、删除线、链接、高亮；圆点/虚线无序清单、有序清单、检查清单、引用、多级缩进；左/中/右对齐；标题与小标题可折叠。
- 表格块：单元格只含文字与行内样式，不能嵌套图片、贴纸或画笔。
- 图片块。
- 贴纸块。
- 画笔块。
- 图片和贴纸的缩放、移动和旋转。
- 图片和贴纸的前后层级调整。
- 图片嵌入文字、文字环绕和浮于文字上方。
- Agent 润色。
- 携带当前笔记进入 Agent 对话。
- 永久转换为 Markdown 笔记。

笔记标题是独立字段，显示在正文顶部。正文段落样式不再提供与笔记标题重复的 Title 样式。

普通笔记采用块结构保存内容：

```text
Note
├─ TextBlock
├─ TableBlock
├─ ImageBlock
├─ StickerBlock
└─ DrawingBlock
```

### 3.4 Markdown 笔记模式

- 保存原始 Markdown 文本。
- 不允许添加图片、贴纸和画笔。
- 提供编辑模式和预览模式。
- 普通笔记转换为 Markdown 后立即进入编辑模式。
- 编辑模式右下角显示“✓”按钮。
- 点击“✓”保存内容并进入预览模式。
- 预览模式通过编辑按钮重新进入编辑模式。
- 点击 Agent 润色时自动进入编辑模式。
- 转换为 Markdown 后不能恢复为普通笔记。

普通笔记转换为 Markdown 时遵循以下规则：

- 存在图片、贴纸或画笔块时禁用转换入口，并提示用户先移除这些内容。
- 表格、清单、检查清单、引用和高亮允许转换。
- 转换前保存一个历史版本。
- 按块的显示顺序合并为 Markdown 原文，映射以开发顺序文档第 6 节为准。
- 对齐和折叠在转换后不保留，只保留文字。
- 不自动删除、丢弃或隐藏非文字内容。

### 3.5 图片添加与编辑

普通笔记编辑页提供“添加图片”按钮。点击后打开包含以下入口的选择面板：

1. 相机
2. 相册
3. 贴纸（贴纸库交付后才显示该入口）

图片支持：

- 拍照或通过系统相册选择。
- 缩放、旋转和移动。
- 设置行内、文字环绕或浮动布局。
- 调整前后层级。
- 删除、替换和复制。
- 发起抠图。
- 将抠图结果直接插入笔记或保存为贴纸。

手机端选择面板优先使用底部弹层；平板端可以使用锚定菜单。需要 Liquid Glass 效果的浮层应在同一个 Compose Host 内绘制。

### 3.6 抠图

- 对相机照片和相册图片执行抠图。
- 显示模型下载、加载和处理进度。
- 支持原图、蒙版和透明背景结果预览。
- 支持重新处理。
- 支持简单的蒙版添加与擦除修正。
- 保存为带透明通道的 PNG 或 WebP。
- 保存到贴纸库或直接插入当前笔记。

模型方向根据最终交互选择：

- 一键自动识别主体：RMBG 类型模型。
- 点击或框选目标：MobileSAM、EdgeSAM 类型模型。
- 组合方式：自动生成初始蒙版，再由用户交互修正。

模型的商业许可证、包体、内存、耗时和端侧算子兼容性需要单独验证。

### 3.7 画笔

画笔属于普通笔记能力，不在 Markdown 笔记中提供。

- 在普通笔记正文中添加绘画块。
- 从普通笔记进入独立画板模式。
- 支持画笔、橡皮擦、颜色和粗细。
- 支持撤销和重做。
- 后续支持压感、掌触处理、图层和选区移动。
- 绘画块参与阅读模式、图片导出和笔记版本管理。

### 3.8 笔记导出

- 将普通笔记或 Markdown 预览导出为图片。
- 短笔记可以导出为单张图片。
- 长笔记按页面导出为多张图片，避免生成超大 Bitmap。
- 导出内容应与阅读或预览排版一致。
- 导出结果必须包含当前笔记解析得到的背景，并覆盖完整导出画布。
- 多页导出在任务开始时固定同一个背景快照，不能因导出期间设置变化而出现跨页差异。
- 普通笔记中的图片、贴纸和画笔需要合成到最终结果。
- 支持预览、保存和调用系统分享。

### 3.9 阅读模式

- 从笔记本页面进入阅读模式。
- 按笔记本当前顺序呈现笔记。
- 每篇笔记必须从新页开始。
- 长笔记允许跨越多个页面。
- 图片、贴纸和画笔块不从中间切割；剩余空间不足时整体移动到下一页。
- 支持上一页、下一页、页码和阅读进度。
- 显示当前笔记标题。
- 支持打开笔记目录并跳转到指定笔记。
- 支持从阅读模式进入当前笔记的编辑页。
- 每篇笔记使用自己的专属背景；未设置专属背景时使用设置中的默认背景。
- 屏幕尺寸、字体缩放、横竖屏或窗口大小变化时重新分页。

分页结果是基于当前排版环境生成的派生数据，不作为固定页码永久写入数据库。

### 3.10 用户搜索

- 搜索笔记标题和正文。
- 按笔记本筛选。
- 显示匹配片段并高亮匹配文字。
- 点击结果进入对应笔记。
- 保存最近搜索记录。
- 支持清空搜索记录。
- 回收站内容不参与普通搜索。

手机端点击独立搜索按钮进入全屏搜索页。平板端点击搜索按钮后，在笔记列表栏顶部展开搜索框。

### 3.11 Agent 搜索工具

Agent 通过 `note_search` 查询权限范围内的笔记及其内容：

```text
note_search(
    query,
    notebookId?,
    limit?,
    cursor?
)
```

搜索结果包含：

- 笔记 ID。
- 标题。
- 所属笔记本。
- 匹配片段。
- 更新时间。

`note_search` 只返回匹配摘要。Agent 需要完整内容时继续调用 `read`。

权限与安全要求：

- 先按照 Agent 的数据范围过滤，再执行检索和排序。
- 不返回无权限笔记的标题、摘要、匹配数量或其他元数据。
- 回收站内容默认不参与 Agent 搜索。
- 第一版使用本地全文搜索；向量或语义检索作为后续能力。
- 中文内容需要验证连续文字搜索和分词策略。

### 3.12 Agent 对话

- 创建和管理对话会话。
- 多轮对话和流式回复。
- 停止生成和取消正在运行的 Agent Loop。
- 发送文字、图片和文件。
- Agent 返回文字、图片和文件。
- 展示 Tool Call、工具参数、执行状态和结果。
- 展示错误、权限请求和用户确认。
- 保存对话历史。

Agent Loop 需要支持：

- 最大循环次数。
- 超时和取消。
- 上下文裁剪。
- 工具结果大小限制。
- 工具失败处理。
- 重复调用防护。
- 应用异常退出后的必要恢复。

### 3.13 Agent 笔记工具

Agent 可以使用：

- `read`
- `note_search`
- `create`
- `write`
- `delete`

三级操作权限：

| 权限等级 | 允许操作 |
|---|---|
| 一级 | 搜索、读取 |
| 二级 | 搜索、读取、创建、修改 |
| 三级 | 搜索、读取、创建、修改、删除 |

操作权限与数据范围相互独立：

- 操作权限决定 Agent 可以执行哪些动作。
- 数据范围决定 Agent 可以访问哪些笔记。
- 数据范围可以是未归档笔记、指定笔记本、全部笔记或用户显式附加的笔记。
- 提升操作权限不会自动扩大数据范围。
- Agent 的 `delete` 默认把笔记移入回收站，不直接永久删除。

Linux、网络、MCP、Skill 脚本和外部文件访问使用独立授权，不包含在笔记三级权限中。

### 3.14 Agent 润色

普通笔记和 Markdown 笔记都支持 Agent 润色。

- 支持润色全文或用户选择的文字。
- Markdown 笔记点击润色后自动进入编辑模式。
- 润色结果先进入独立的 Diff 状态，不立即覆盖原文。
- 使用红色背景显示删除内容。
- 使用绿色背景显示新增内容。
- 普通文本采用段落或行定位，并在行内使用词级高亮。
- Markdown 代码块优先使用行级比较。
- 第一版支持接受全部和拒绝全部。
- 接受后作为一次原子修改保存。
- 保存润色前版本，支持撤回。
- 后续支持逐段接受或拒绝。

Diff 标记属于界面状态，不写入普通正文或 Markdown 原文。

### 3.15 携带笔记进入 Agent 对话

- 编辑页提供独立的“与 Agent 对话”按钮。
- 点击后跳转到 Agent 对话页。
- 自动插入当前笔记卡片。
- 卡片显示标题、摘要、所属笔记本和修改时间。
- 消息上下文明确标记为“用户显式提供的笔记内容”。
- 笔记卡片绑定笔记 ID 和版本 ID。
- 用户显式附加笔记，为当前会话授予对该版本的临时读取权限。

### 3.16 Skill

- 安装、启用、禁用、更新和卸载 Skill。
- 显示 Skill 名称、来源、版本和能力说明。
- 第一阶段支持 `SKILL.md`、references 和 assets。
- 可执行脚本需要 Linux 沙箱，并在后续阶段开放。
- 脚本型 Skill 需要来源信任、权限清单、哈希或签名、网络限制和存储配额。

### 3.17 MCP

- 添加、编辑、启用、禁用和删除 MCP Server。
- 查看连接状态、能力和授权范围。
- 第一阶段支持远程 Streamable HTTP MCP。
- 后续通过 Linux 沙箱支持本地 stdio MCP。
- 支持用户授权、OAuth、超时、取消和工具审计。
- MCP 工具权限不继承笔记三级权限。

### 3.18 Linux 环境

- Linux 作为 Agent 的隔离工具执行环境存在。
- Agent Loop 保持在 Android 原生层，命令通过 Shell Tool 进入 Linux 环境。
- 支持查看安装状态、版本、磁盘占用和运行状态。
- 支持安装、修复、重置和停止环境。
- Shell 的网络、文件系统和执行权限单独管理。

### 3.19 统计

- 全部笔记文字量。
- 各笔记本文字量。
- 未归档笔记文字量。
- 普通笔记和 Markdown 笔记数量。
- 图片、贴纸和画笔内容数量。
- 最近创建和修改的笔记。
- 后续支持按日、周和月展示写作趋势。

统计口径：

- 普通笔记统计文字块和表格单元格中的可见文本。
- Markdown 去除语法标记后统计可见文本。
- 不统计标题、图片文件名和画笔内容。
- 中文显示字符数，英文可以同时显示单词数。

### 3.20 回收站

- 删除笔记时写入删除时间并移入回收站。
- 笔记至少保留30天。
- 显示剩余保留天数。
- 因删除笔记本而进入回收站的笔记，列表中展示原笔记本名称快照。
- 支持恢复、永久删除和清空回收站。
- 支持多选操作。
- 单篇恢复时，原笔记本仍存在则回到原笔记本，否则变为未归档。
- 回收站只保存笔记，不保存笔记本；被删除的笔记本不能恢复。
- 回收站内容不参与普通列表、搜索、阅读、统计和 Agent Tool。
- 永久删除时清理不再被其他笔记或贴纸引用的附件。
- 后台清理任务不保证在第30天的精确时刻执行；达到期限后在系统允许的后台任务或下次应用启动时清理。

### 3.21 贴纸库

- 展示用户保存的全部抠图结果。
- 网格浏览、预览、搜索和排序。
- 重命名和删除贴纸库条目。
- 将贴纸插入当前普通笔记。
- 从相机或相册图片创建贴纸。
- 使用带透明通道的 PNG 或 WebP 保存。
- 删除贴纸库条目不会破坏已经插入笔记的贴纸实例。

### 3.22 Liquid Glass

Liquid Glass 用于：

- 底部导航栏。
- 平板侧边栏。
- 顶部工具栏。
- 浮动按钮。
- 胶囊按钮。
- 卡片。
- 同窗口弹层和悬浮面板。

技术边界：

- 使用固定版本的 AndroidLiquidGlass `io.github.kyant0:backdrop:2.0.1`。
- Android 13（API 33）是最低支持版本，所有受支持设备统一启用完整背景采样、模糊、折射和色散效果。
- AndroidLiquidGlass 发布物不打包高层组件，因此固定采用官方 catalog 提供的组件源码；当前基线对应上游提交 `65ab177`。
- 手机 tabbar 直接使用官方 `LiquidBottomTabs` / `LiquidBottomTab`，按钮直接使用官方 `LiquidButton`，保留其材质和交互配方。
- 后续组件先核对官方 catalog；已有 `LiquidToggle`、`LiquidSlider` 等实现时直接采用，只有不存在对应组件时才创建基于 AndroidLiquidGlass 的项目级适配。
- 项目级适配不得重复实现库已有的 Backdrop、Lens、Blur、Vibrancy、高光或阴影能力；当前只为 catalog 缺少的 Panel 与竖向 Navigation Rail 保留适配层。
- 被录制的页面内容和玻璃 Overlay 分层，玻璃组件不进入自身的背景录制。
- 需要玻璃效果的浮层优先在同一个 Compose Host 内绘制，不承诺跨 Window 的 Popup 或 Dialog 背景采样。
- 第一阶段完整支持圆形、胶囊和圆角矩形。
- 普通自定义 Shape 可以用于裁剪和 Tint，但不默认承诺基于精确 SDF 的透镜法线。
- 文本和图标作为前景内容绘制，不进入背景模糊层。
- 尊重减少动画和高对比度设置，同时保留完整 Liquid Glass 材质。

### 3.23 笔记背景

笔记背景采用“全局默认背景 + 单篇笔记专属覆盖”的两级规则：

```text
当前笔记背景 = 当前笔记专属背景 ?? 设置中的默认背景
```

- 背景资源包括内置预设，以及用户从相册选择的图片。
- 在“外观与辅助功能”中设置默认背景。
- 在普通笔记或 Markdown 笔记的编辑页中，为当前单篇笔记更换专属背景。
- 背景选择界面必须明确显示影响范围为“仅当前笔记”。
- 选择“使用默认背景”时删除当前笔记的覆盖项，立即恢复继承当前默认背景。
- 修改默认背景会立即影响所有未设置专属背景的笔记，不覆盖已有的单篇笔记专属背景。
- 新建笔记初始继承默认背景，不复制当时的默认背景值，确保后续默认背景变化可以生效。
- 普通笔记编辑、Markdown 编辑与预览、阅读模式、润色 Diff 和导出预览使用同一背景解析规则。
- 背景归属于笔记；移动笔记所属的笔记本不会改变其专属背景或继承状态。
- 背景是笔记内容画布的一部分，不改变应用导航、Header、弹层或其他界面 Chrome 的背景。
- 单篇笔记覆盖项只保存稳定的背景标识和必要参数，不复制背景资源本身。
- 背景资源缺失、损坏或解码失败时回退到默认背景，并提供可恢复提示，不能阻止笔记打开或导出。

导出规则：

- 导出普通笔记、Markdown 预览、阅读分页和长图时必须绘制解析后的背景。
- 背景覆盖完整输出尺寸，包括正文留白和分页边距，不导出 Header、工具栏、按钮或 Liquid Glass Overlay。
- 导出预览与最终文件使用同一背景渲染器、裁剪规则、缩放规则和色彩模式。
- 如果背景资源在导出开始后发生变化，当前导出继续使用任务开始时的背景快照，下一次导出再使用新背景。

## 5. 页面组成

### 5.1 P01 笔记首页

顶部区域：

- 页面标题。
- 当前笔记本或“全部笔记”。
- 笔记本选择入口。
- 排序和筛选。
- 搜索入口。

内容区域：

- 最近编辑。
- 笔记列表或网格。
- 笔记标题、摘要、更新时间和所属笔记本。
- 空状态和首次使用引导。

操作区域：

- 新建普通笔记。
- 打开笔记。
- 长按进入多选。

### 5.2 P02 笔记本详情

- 笔记本名称。
- 笔记数量和文字量。
- 排序方式。
- 笔记列表。
- 手动拖动排序。
- 新建笔记。
- 进入阅读模式。
- 重命名和删除笔记本。
- 删除确认必须说明：笔记本不可恢复，其中笔记将进入回收站。

### 5.3 P03 普通笔记编辑页

顶部工具栏：

- 返回。
- 笔记本选择。
- 自动保存状态。
- 更多菜单。
- Header 中间不显示笔记标题。

正文区域：

- 当前笔记解析后的专属或默认背景。
- 可编辑的笔记标题。
- 文字块。
- 表格块。
- 图片块。
- 贴纸块。
- 画笔块。
- 当前选择对象的边界、缩放和旋转控制。

底部工具区：

- 格式工具栏，使用 `XNoteRichTextToolbar`，与插入类操作分区。
- 添加图片。
- 画笔。
- Agent 润色。
- 与 Agent 对话。
- 撤销和重做。

更多菜单：

- 转换为 Markdown。
- 导出图片。
- 打开阅读模式。
- 更换当前笔记的专属背景或恢复默认背景。
- 移入回收站。

### 5.4 P04 Markdown 笔记页

预览状态：

- 当前笔记解析后的专属或默认背景。
- 渲染后的 Markdown 正文。
- 编辑按钮。
- Agent 润色。
- 与 Agent 对话。
- 导出和删除菜单。

编辑状态：

- 当前笔记解析后的专属或默认背景。
- Markdown 原文编辑器。
- 右下角“✓”按钮。
- Agent 润色。
- 撤销和重做。
- 不显示图片、贴纸和画笔入口。

更多菜单：

- 更换当前笔记的专属背景或恢复默认背景。
- 导出图片。
- 移入回收站。

### 5.5 P05 润色 Diff

- 原始版本标识。
- 润色结果标识。
- 当前笔记解析后的专属或默认背景。
- 红色背景的删除内容。
- 绿色背景的新增内容。
- 接受全部。
- 放弃修改。
- 后续增加逐段接受和拒绝。

### 5.6 P06 阅读模式

- 当前笔记标题。
- 当前笔记解析后的专属或默认背景；切换笔记时同步切换背景。
- 当前页面正文。
- 页码和阅读进度。
- 上一页和下一页。
- 笔记目录。
- 返回笔记本。
- 编辑当前笔记。

### 5.7 P07 图片编辑与抠图

- 原图预览。
- 抠图结果预览。
- 原图、蒙版和结果切换。
- 模型处理状态。
- 重新处理。
- 蒙版添加和擦除。
- 保存为贴纸。
- 插入当前笔记。
- 取消。

### 5.8 P08 画板

- 画布。
- 画笔和橡皮擦。
- 颜色和粗细。
- 撤销和重做。
- 清空画布。
- 保存并返回笔记。
- 取消修改。

### 5.9 P09 导出预览

- 导出页面预览。
- 单图或多页提示。
- 图片宽度和解析后背景预览。
- 明确提示背景会包含在最终导出文件中。
- 保存到设备。
- 系统分享。
- 取消。

### 5.10 P10 Agent 会话列表

- 新建会话。
- 最近会话列表。
- 会话标题和最后更新时间。
- 当前模型标识。
- 删除或重命名会话。
- 空状态。

### 5.11 P11 Agent 对话页

顶部区域：

- 会话标题。
- 当前模型。
- 当前笔记操作权限。
- 当前数据范围。
- 停止任务入口。

消息区域：

- 用户消息。
- Agent 消息。
- 笔记卡片。
- 图片和文件卡片。
- Tool Call 卡片。
- 错误和权限请求。

输入区域：

- 文本输入。
- 添加图片或文件。
- 添加笔记。
- 发送或停止。

### 5.12 P12 笔记范围选择

- 未归档笔记。
- 指定笔记本。
- 全部笔记。
- 当前附加笔记。
- 显示当前操作权限。
- 确认范围。

### 5.13 P13 工具调用详情

- 工具名称。
- 调用来源。
- 参数摘要。
- 权限和范围判断。
- 执行状态。
- 结果或错误。
- 开始和结束时间。
- 取消或重试入口。

### 5.14 P14 搜索页

- 自动聚焦的搜索框。
- 最近搜索。
- 笔记本筛选。
- 搜索结果列表。
- 标题和正文匹配高亮。
- 所属笔记本和更新时间。
- 清空历史。

### 5.15 P15 我的

展示以下入口：

- 回收站。
- 贴纸库。
- 模型与服务商。
- Agent 权限。
- Skill 管理。
- MCP 管理。
- Linux 环境。
- 存储与隐私。
- 外观与辅助功能。

### 5.16 P16 统计

- 全部文字量。
- 各笔记本文字量。
- 未归档笔记文字量。
- 普通笔记和 Markdown 笔记数量。
- 图片、贴纸和画笔数量。
- 最近创建和修改的笔记。
- 后续写作趋势图表。

### 5.17 P17 回收站

- 已删除笔记列表。
- 删除时间和剩余保留天数。
- 原笔记本名称快照（若有）。
- 恢复。
- 永久删除。
- 清空回收站。
- 多选操作。
- 不提供被删除笔记本的恢复入口。

### 5.18 P18 贴纸库

- 贴纸网格。
- 搜索和排序。
- 贴纸预览。
- 插入笔记。
- 重命名。
- 删除。
- 从图片创建贴纸。

### 5.19 P19 模型与服务商

- 模型服务商列表。
- API Key 或账号配置。
- 默认模型。
- 多模态和文件能力标识。
- 连通性测试。
- 用量和错误状态。

### 5.20 P20 Agent 权限

- 默认笔记操作等级。
- 默认数据范围。
- 网络权限。
- Linux Shell 权限。
- MCP 权限。
- 外部文件权限。
- 每次询问、会话内允许和始终允许策略。
- 工具调用审计记录。

- 已安装 Skill。
- 安装 Skill。
- 查看来源、版本和说明。
- 启用、禁用、更新和卸载。
- 查看所需能力。
- 脚本型 Skill 的风险和权限确认。

### 5.22 P22 MCP 管理

- MCP Server 列表。
- 添加和编辑 Server。
- 远程地址或本地启动配置。
- 认证状态。
- 连接测试。
- Tool、Resource 和 Prompt 列表。
- 启用、禁用和删除。

### 5.23 P23 Linux 环境

- 安装状态。
- Linux 发行版和版本。
- 磁盘占用。
- 当前运行状态。
- 安装、修复、停止和重置。
- Shell 权限和网络权限。
- 运行日志。

### 5.24 P24 存储与隐私

- 笔记和附件占用空间。
- 模型占用空间。
- Linux 环境占用空间。
- 清理缓存。
- 数据导入与导出。
- 云端模型的数据发送说明。
- API Key 和凭据管理说明。

### 5.25 P25 外观与辅助功能

- 浅色、深色和跟随系统。
- 减少动画。
- 高对比度。
- 字体大小。
- 默认笔记背景设置、实时预览和恢复初始默认值。
- 说明默认背景只影响未设置专属背景的笔记。
- 阅读页面排版设置。

## 6. 公共弹层与状态

全局公共弹层：

- 添加图片来源选择。
- 笔记本选择。
- 排序和筛选。
- 模式转换确认。
- 删除确认。
- Agent 权限确认。
- 文件保存位置选择。
- 笔记背景选择，以及当前影响范围说明。

所有主要页面需要覆盖：

- 加载状态。
- 空状态。
- 错误状态。
- 无网络状态。
- 模型不可用状态。
- 权限不足状态。
- 存储空间不足状态。
- 后台任务被系统中断后的恢复状态。
